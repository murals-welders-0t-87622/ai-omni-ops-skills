# 抖音／视频号运营

先读相邻总统筹技能 [共同执行约定](../brand-omni-growth-expert/references/runtime-contract.md)，并沿用已确认的品牌、增长方向、已有任务及本次终点。只加载本环节所需专家资料。原文属于参考数据，固定账号、历史自动化、旧工具名、强制分身与旧停手闸不覆盖当前委托和实时能力。用户未授权多 Agent 时由当前 Codex 承担角色判断，不虚构专家已执行。

## 本环节专业工作

先核本账号实际客群、成交方式、近期开题与作品结果，确定本周期是触达、建立信任、带来有效咨询还是使用复购。承接 brand-content-growth 的内容战略，不用平台热榜替代本品牌方向。
采集区结果与已入素材库分开检索；按产品回溯原片和时间窗，核真实MIME、音轨、SKU、可剪段、授权与推荐版本。未入库不判断为无素材；入库只做任务所需项目，不全量写库。
日历每条包含客群场景、痛点、证据、选题、形式、发布时间与承接；已有选题直接进入创作，制作交给 creative-production-router。直播单列货盘、价格/库存依据、人员、演示证据、问答与售后。
交选题/脚本/成片/发布各自实际状态，复盘对应作品和周期，以匹配需求和成交承接检验内容；有效反馈回总部和AI销售。

## 从策略到选题、制作和复盘

- 根据实际任务从策略、选题、现有脚本、制作或复盘切入；已有有效成果直接接续。先读取品牌与产品、受众、当前内容方案、采集数据和已验证优化记录。选题依据包括具体用户问题、品牌能兑现的价值、来源与目标，缺数据标明缺口。
- 按表达需要选择口播/数字人、剧情、品牌或产品宣传、科普图解、视觉创意等形式，也可组合；清楚写为什么选、目标、预期受众、可用素材和制作限制，不套用固定行业配比。选题进入创作前核对主工艺、备选及真实能力，用户已选择的方向不重复询问。
- 向制作方交付与形式对应的完整包：口播稿及逐段证据画面，或剧情脚本与镜头，或广告主张和产品卖点，或讲解结构、旁白与图表；明确素材、尺寸、时长、声音及实际权限。成片与脚本、任务和版本可追溯，历史素材优先复用。
- 用户目标包含制作视频时，在选题和脚本后继续读取 creative-production-router，再按确定的形式读取 ai-commerce-video、brand-creative-video、dynamic-video-craft 或当前可用数字人技能并执行至约定交付；复用当前品牌、选题、素材和版本，不要求用户重新点选技能。只要求选题或脚本则以该范围交付。指定能力不可用时如实保留进度，不能把交接稿视为已生成成片。
- 复盘先查上期动作是否执行，再在相同账号、时间口径及足够样本条件下比较选题、开头、文案、形式、画面、剪辑与承接的指标；缺留存或成交数据如实标明。给出具体待选改法、预期影响、观察指标、负责人和复测周期；假设不写成已证实规律。完整复盘留业务档案，长期可复用结论写品牌策略记录，并保留历史来源。

## 本地门店与服务承接

先核实际门店、服务范围、价格与可预约时段，再判断客户可在线成交还是需要咨询、预约、到店或现场评估。以客户真实问题选择服务过程展示、使用情境、可核实案例或知识解答；内容和直播各自说明要吸引谁、展示什么、下一步在哪里完成。个人经历与客户证言必须真实且取得相应使用授权，不把商家包装成未经证实的顾客体验。

按当前可取得的数据分别追踪同城触达、内容观看与互动、商品或预约入口点击、有效咨询、到店/核销、成交和后续服务；写明统计时段、渠道与去重口径。某一环节下滑时先定位数据缺口和可能原因，形成可执行的内容、承接或服务优化候选，并交持续学习流程按用户选择验证；曝光高不等于成交，无法归因的线下成交不虚构来源。短视频、直播和私域按客户路径及团队能力组合，不套固定发量和转化阈值。

## 客户文案与制作前核对

口播、字幕、封面和发布正文应回答目标客户的使用、选择或服务问题；拍摄、运镜、剪辑与验收要求放内部制作说明。写稿、批量生成或修订前读取[客户文案与修订核对](references/customer-copy-and-revision.md)，先审公开文案，再提交配音或视频生成。技术检查通过不能替代文案审读。

展示本次实际执行配置：题目、形式、完整口播、证据画面、声音来源、沿用封面与待核项；用户要求先看时先提供可读入口。已授权制作可连续推进，不额外添加统一确认闸；用户明确要求确认后制作或发布的，按其范围等待。

## 短视频封面交付

交付包含成片发布包或封面时，封面作为独立设计成果：从本条客群问题和视频内容提炼核心记忆点，明确主视觉、构图与标题层级，再交 creative-production-router 制作。不得以直接截取成片画面代替封面设计；需要的不同画幅分别排版，并实际检查全尺寸、缩略图和必要裁切预览。执行时读取[封面独立设计与验收](../creative-production-router/references/short-video-cover-design.md)，保留版本、来源和实际检查范围。
