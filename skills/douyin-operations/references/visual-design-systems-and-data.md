# 设计系统、视觉数据与图表：UI UX Pro Max 视频适配

配套原文和数据逐项见 visual-design-source-index.md 的 UI UX Pro Max。先读原项目中文 README、数据目录说明及使用授权；需动效时查 motion.csv，比较与图表查 charts.csv，色彩查 colors.csv，字体查 typography.csv，风格查 styles.csv，行业建议查 ui-reasoning.csv。原始数据库是查询材料，不等于已经安装或已验证的生产能力。

## 从 brief 到系统，而非抄行业预设
确定视频的内容类型、受众知识、观看尺寸、事实证据和品牌约束；从候选资料中选表达逻辑，再建立设计系统。产品类型到风格的映射仅是可反驳线索：先检查数据更新时间、受众、实际素材、品牌规范和视频用途。不得把网页中的按钮状态、操作动线、营销页面结构照搬为不可交互的视频叙事。

项目级系统包含：画幅/安全区、色彩语义、文字层级、字体回退、网格和间距、描边/圆角/阴影规则、图像和图标语法、图表语法、运动节拍、字幕和声音。设全片主规则，再为具体镜头明确必要覆盖；变化要有内容理由，且不破坏已确认的视觉合同。将配置记录为可复用的变量与实际组件参数，不是只写“高级、现代”。

## 色彩、字体与图像
为背景、主文字、次文字、强调、正反状态和图表序列分别设角色；同一色在全片含义稳定。实图上直接检验标题、字幕和细字对比，包括变化过程中的最亮/最暗帧。不要仅用红绿或单一色相表达类别：使用位置、形状、文字或线型同步编码。禁止为了高级固定一种深色或限定某类颜色；用户品牌规范优先。

为中文、英文、数字、标点分别核字体覆盖和授权；标题、解释、数据和字幕使用不同阅读层级。搭配建议必须在中文实字、竖屏、真实文案和实际环境中检验，避免在线字体加载失败后换行或错位。图标尽量统一同一授权来源与风格，语义靠内容验证，不拿网页 UI 图标代替真实产品证据。

## 数据到画面
先回答观众要比较什么，再选视觉：时间变化用带时间轴的趋势图；离散项目比较可用排序条形；组成占比先说明整体、口径和合计；步骤路径使用有明确先后和条件的流程；价格算式逐项显示单位、输入、输出与适用范围。小样本或缺少尺度不要强画趋势；未披露的数据不能用数值、进度条或柱高暗示真实结果。

每幅数据画面先查原始来源、统计时间、数量、计价单位、分母和比较基准。轴、零点、方向、标注、来源、单位、四舍五入及动态前后状态一致；过程动画不能让观众误把过渡值当事实。关键数字优先直接标出，图例和数据表的可读性要随屏幕缩小检查。真实案例与示例计算清晰分开。

## 运动与技术方案
将运动表中触发、时长、缓动、代价和禁忌转换为视频的语义动作：一句事实出现、图像揭示、数据变化、比较切换或相邻镜头接力。网页中的 hover、点击、滚动仅可模拟成确实有叙事价值的可见动作，不能伪造真实操作。让画面进入、关键信息落定、阅读、退出构成完整节拍；强调动作与口播关键词对齐。减少重复闪烁、无目的弹跳、抖动和无意义数字滚动。

Remotion 以帧驱动插值、时间分段、固定随机种子与可复现采样；HyperFrames 以项目支持的声明式时间轴和可寻址场景渲染，动画必须可确定 seek。选择任何引擎都要求预览与出片同源，同一素材、时间与场景代码贯穿；替换素材需重新校验裁切和字幕安全。第三方字体、图片、图标与数据分别核实许可，不把仓库许可证自动套到外链资产。

## 检查和记录
设计系统文件列出实际应用到的镜头、数据来源、字体/图片文件、图表口径和拒绝的候选。导出前检查所有关键画面在手机尺寸下的阅读速度、截图真实性、对比度、图表标签、单位、事实边界及时间轴；对自动警告记录成因并通过真实播放复核，不以规则评分替代观看。
