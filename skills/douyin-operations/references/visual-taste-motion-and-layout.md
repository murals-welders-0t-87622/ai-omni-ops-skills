# 审美、镜头动效与反模板：Taste 方法的视频转译

先读 visual-design-source-index.md 中 Taste 主文和按需全文：layout、imagery、motion、type、colour、copy、critique、scenes、tells；需要模拟真实工作台或业务系统再读 app-screens。该来源分析网页；其中滚动、悬停、可交互控件应转译成用户看得懂的线性时间，不直接当视频指令。

## 先构思，再构成
把内容改写成一句明确的主张与证据链。确定本片独有的主体、关系和视觉世界：例如具体订单如何进入规则、真实案例的前后变化、物体从输入到输出的路径。先寻找适配的图片、界面、数据与合法素材，再建立排版，而不是先选择酷炫动效寻找内容填充。真实资产不足时以清晰标注的示意图、合法生成图或有依据的图解解决，不能伪造事实。

每个镜头设计一张“视觉事件卡”：叙事功能；当前观众应看哪里；画面内主体及其视觉关系；信息出现的先后；图像尺寸/焦点；内容准确性；动画开始、落定、阅读和离场；与上镜的语义接力；字幕、来源和安全区域。整体靠少量固定视觉规则保持一致，每个镜头的画面组织要对内容负责。用户明确要求每镜不同模板时，比较布局、主体、比例、层级与运动路径，不以变色、调词或左右翻转冒充原创。

## 构图与信息密度
设计可用：主标题与大幅局部特写、全屏材料、物件剖面、嵌套图窗、数据密集的真实截图、图表与注释、局部连续缩放、图像与章节字交叠、上下分区、文字主导的关键判断、时间/空间路径。各类之间建立明显节奏；不把“画面饱满”误解为每个角落塞字，留白必须让焦点、阅读路径或视觉呼吸更清晰。背景不能因为缺素材变成大面积无意义空洞。

图片需要有身份与作用：主体、证据、空间、情绪、比较、细节。摄影不能用空泛渐变或几何卡片代替；图像与窗口的比例预先匹配，核实人物脸部、文字、Logo、主体边缘在实际运动中不被裁掉。多图同项目保持光线、材料、颜色、相机和角色连贯；变化服务剧情而不是来源混杂。

排版用明确字号差、字重、行距和对齐建立远近；手机端是重新审视的实际成片构图，不是把电脑预览等比缩小后自认合格。严查乱码、错字、截断、字幕覆盖、对比不足和视线竞争。颜色区分背景、焦点和解释，照片颜色处理应保留重要事实和肤色；颜色选择服从品牌与内容，不把任一色系规定为固定高级答案。

## 动态词汇：必须有叙事作用
先回答四问：什么变化、为什么此时、观众应看哪里、落定后阅读多久。一个主动作可搭配一到两个辅助动作，其余保持稳定。可依内容选：文字逐行揭示；图像遮罩打开；从远景推到证据细节；一张图承接多个注释；图形沿路径组装；同屏对照切换；数值按真实公式变化；镜头沿时间线推进；对象在前后关系中变形；图像从连续画面接到实物细节；页面结构转换为全屏图表；章节结尾以形状、方向或内容连入下一镜。

镜头运动要有起始、路径、缓动、停靠和必要阅读期，文字和字幕不随背景镜头随机漂移；复杂动作分层、有先后，不同时抢占中心。数字人优先稳定主体、避免不必要缩放或额外抖动；先看原始人像视频稳定性、口型与水印，再检查叠层。数字和图表过渡要维护真实单位、基准和方向，不能以动态制造未发生的增长。

## 反模板和可执行复盘
把相邻镜的结构缩略图排成联系表，检查是否同一种大标题+容器+图标反复换字；必要时重做核心视觉，而不只是加粒子、霓虹、旋转圆环、假坐标或虚构数据。通篇统一的角标、线条和语气可保留，但每个信息图都要有不同且可解释的表达职责。无意义英文、假徽章、无解释数据、同款空卡和假 UI 均需删或替换成真实内容。

先无动效逐帧审构图，再以短片检查运动节拍，最后在完整成片里审镜头前后关系、音乐/口播、字幕和手机阅读。检查每个镜头入场、落定、出场及连接点，识别闪帧、停滞、错位、裁切、空画面、素材缺失或人物抖动。没实际播放或没实际听到的部分必须明确写未验证。
