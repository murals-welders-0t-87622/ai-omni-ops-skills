# 从方法到可播放样片

当用户要求“做几支样片”，交付真实MP4与清楚的形式对照。HTML、工程、分镜与关键帧是制作依据，不替代视频。可以在不改变业务主框架的前提下，先用小型非品牌演示核工艺，再应用到真实品牌。优先按用途与素材选择差异明显的形式，避免只改配色。

## 四种实际出样路线

|形式|主要运动与视觉|适用任务|本次验证范围|
|---|---|---|---|
|白板手绘|笔触绘制、图形建立、路径连线和镜头微动|使用说明、方法讲解、服务流程|真实帧、视频、文字与线条间距|
|动态数据|数值变化与等额立体堆叠同步|经营解释、报告、指标拆解|同一数据状态驱动人数、比例、金额与几何|
|3D商品外观|真实三维材质/灯光、旋转、开合、相机与阴影|概念外观、已有可用模型的产品展示|WebGL真实输出、上下边界、屏幕文字；不是实物结构/性能证明|
|国风水墨|固定纸纹、分层山水、留白、墨色、镜头与字形|品牌意境、文化节日、文旅/茶等内容|动态合成、深度、结尾对比；不是证明掌握所有水墨/笔刷引擎|

上述为2026-10-26一次非品牌练习的实际验证：4支各18秒、1280×720、24fps，原生HyperFrames 0.8.186逐帧渲染与本地原创程序化配乐；4组乱序时间定位结果一致，最终H.264/AAC文件完整解码、画面抽检与播放器元数据通过。单机单worker渲染约29—32秒/支是当次环境观察，不是其他机器的速度承诺。未人工全程听审，不外推全部16类教程样片/Remotion路线/品牌经营效果均通过。这里的尺寸、时长、音乐和主题不是新项目默认限制。

## 可复用的制作纠错

**宿主调用时间轴时返回简单值。** 浏览器自动化桥不应返回GSAP Timeline、Three.js Renderer或整个DOM对象。它们可能引发巨大的跨进程序列化，表现为定位时间后一直卡住。用无返回值的桥，例如：

```javascript
window.renderAt = (seconds) => {
  timeline.seek(seconds, false);
};
```

Canvas/3D画面必须实际随时间更新；保留框架要求的seek事件或回调。顺序、乱序和相同时间重访都要检查，不能只等页面ready就判断有动画。

**一个数据状态驱动所有表现。** 先从同一计算状态得到人数、转化率、金额、块数和标签，再绘制。不要金额用easeOut、人数用smoothStep，导致动画中途数学矛盾；人数为离散值时先一致取整，再推导相应比例和金额。数值滚动不应创造业务上不存在的含义，假设/真实数据明确区分。

**在最终媒体里复核版式。** 线条可能穿过副标题，3D抬盖可能侵入顶栏，深色山水可能盖住结尾字。检查对象运动的最高/最低点及过渡两侧，用实际视频抽帧复查；CSS容器和lint通过不能证明Canvas内部无遮挡。

**音频处理之后再核时长。** 响度归一化、重采样和编码可能增加尾部延迟。本次处理曾多出0.1秒，已在真实配乐淡出之后按18秒镜头终点裁齐。旁白项目应保留真实尾词与尾音，不能把固定裁切变成截断对白的通用规则。核音轨非静音、峰值/时长及完整解码，测量不等实际听审。

**源码与冻结包分开。** 常规工程保留第三方库为单独文件，便于审核和有效lint；把整个Three.js/GSAP内联后，库中未用于画面的Math.random/requestAnimationFrame可能触发静态告警。冻结包仅作特定调试/交付适配，不能因此全局关闭确定性校验。往HTML注入JS字符串时，用替换函数返回内容，避免JavaScript的 `$&`、`$'` 等替换规则意外改写脚本。

**每项目一个明确根入口。** 多支样片用独立项目或已定义的变量系统，不在同一根目录放多个被运行时同时发现的根composition。后者可能造成重复发现或重复音轨。

**字体与运行环境要实查。** 冻结必要字体、检查实际用字并观察最终帧；字体加载成功不证明所有字都用到了预期字形。已有浏览器用当前CLI支持的正式路径参数指定；本次验证可用HYPERFRAMES_BROWSER_PATH，不据旧文档猜所有版本相同。不为本地预览关Web安全，不为出样重启Docker或改供应商账号。字体/代码库/声音各自核许可，不把本地字体文件自动上传公开Git。

## 出样验收与归档

先代表帧与短运动，再逐支渲染。保存源码/时间轴、真实库版本及hash、素材与声音来源、原生检查结果、真实渲染耗时和最终文件回读。原片与修订版分别保留；最终音量/裁切处理生成新交付，旧稿不覆盖。合集与单片都核解码、章节和播放入口，不能只查文件后缀。

品牌事实和用户项目留授权中台或项目目录。通用方法与已核边界进入本技能；未实现的工艺继续标候选，不能把一轮出样说成全能力验收。
