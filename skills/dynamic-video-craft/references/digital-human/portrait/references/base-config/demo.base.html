【v9 规范要点 · 下半区 2:1】 ① 底色 #F6F5EC 暖米底，不是 #E9EDF3 浅蓝灰。
② 所有卡片必须 8px solid #1A1A1A 黑粗边框 + border-radius:28px + 彩色偏移硬阴影（box-shadow: 6px 6px 0 #C7FF2F），禁止使用模糊阴影。
③ 主卡内部必须信息丰满（ctitle / items3 / items4 / versus / bstat 五选一），vs 列加 max-height:100% + overflow:hidden 防止撑爆主卡下方。
④ 每帧 5 区完整：① 顶部章节条 (y130–240) · ② 主卡 (y280–1080) · ③ 字幕条 (y1110–1270) · ④ 下半区 (y1310–1740) · ⑤ 页脚 (y1770–1810)。
⑤ 字幕条最多 2 行；超过 2 行 → 字幕按句滚动，其余画面静止。
⑥ 关键词用荧光色块（#C7FF2F / #FE6449 / #76D5FE / #FDE676）+ 加粗下划线包裹。
⑦ 【v9 强化】每个画面左下"随手记" .sticky 占 2/3：flex:0 0 calc((1000-18)*2/3)≈654px，3 胶囊标签 (NOTE 0X) + 3 行手写，黑粗边框+圆角+荧光绿偏移阴影。
⑧ 【v9 新增】右下 5 主题卡/dh/note 占 1/3：flex:1 ≈ 327px，与左 sticky 精准 2:1，gap=18。
⑨ 无数字人段：右下放 5 个主题卡，当前正在播的高亮荧光绿+下沉阴影。
⑩ 有数字人段：数字人占右下 flex 1，间距由 flex gap 18 + flex 容器 100% 内部 ≥30px 不碰其它元素。
⑪ 顶部章节条 / 主卡 / 字幕条 / 页脚 左右统一 left:40 / width:1000 对齐。
⑫ 竖版 1080×1920（缩 0.5 → 540×960），横版 1280×720 16:9（缩 0.5625 → 720×418）。
⑬ 出图：仅 create_design_work + gpt-image-2 + 信息图海报 + injectBrandProfile=false，通道故障期用 .ai-pending 占位（绝不降级 PIL）。
⑭ v9 量化验收：Playwright + boundingClientRect 实测 sticky.w ≈ right.w × 2，杜绝肉眼漏检。
⑮ 【v10 新增】主卡带图模板：mc-imgleft（左图 42% + 右文 kicker/标题/3要点/2数据卡）与 mc-imgtop（上图 34% + 下 3 卡 + 标签）。图内用 .img-ph 占位，正式渲染由 gpt-image-2 出真图，绝不降级 PIL。
