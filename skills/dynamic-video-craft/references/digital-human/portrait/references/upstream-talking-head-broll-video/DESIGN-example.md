# DESIGN.md · 视觉设计判断文件

> 本文件是《模型超市》口播视频的**唯一视觉裁决依据**。
> 所有数值来自对参考视频 `下载.mp4` 的逐像素实测（非目测、非推断），测量脚本见 `_ref_measure*.py` / `_ref_sub.py`，原始日志见 `_m3.log` / `_sub.log`。
> 结构遵循《审美.txt》要求的 9 项内容：画幅 · 颜色 · 字体 · 背景与材质 · 留白与版式 · 常用视觉组件 · 动画节奏 · 必须做到 · 绝不能出现。

---

## 0. 设计读取（Design Read）

**Reading this as**：中文知识型口播长视频（240s / 271 条 SRT cue），面向 AI 工具决策者，采用**编辑感纸质拼贴 + 暖米色信息看板**语言，倾向 Remotion 程序化控制 + 实拍数字人复合布局。

### 三旋钮（取自 taste-skill 方法，按本片调校）

| 旋钮 | 值 | 依据 |
|---|---:|---|
| `DESIGN_VARIANCE` | **6** | 参考视频只用 2 种主导布局交替（SPLIT 50% / FULL 45%），克制而非炫技。变化来自**内容组件**，不是来自版式乱变。 |
| `MOTION_INTENSITY` | **4** | 实测无花哨转场，默认硬切；动效只用于信息入场。运动服务于阅读，不服务于表演。 |
| `VISUAL_DENSITY` | **3** | 单帧只有 1 个主角 + 大量暖色场留白。 |

> **反默认纪律**：禁止 AI 紫渐变、禁止居中英雄区压深色 mesh、禁止三等分卡片、禁止全局玻璃拟态、禁止无意义无限循环微动画。这些是大模型的默认审美，本片一律不用。

### 2.1 主色板（实测采样，非设计师臆造）

| 角色 | 色值 | 实测来源 |
|---|---|---|
| **画布底色** | `#E7D5B7` | 103 帧采样中 85% 一致（暖米 / 浅沙） |
| 卡片纸面（浅） | `#F4E7D6` | B-roll 卡片中位色上界 |
| 卡片纸面（深） | `#DFCDB4` | B-roll 卡片中位色下界 |

### 2.2 强调色（每帧最多 2 处，取自 collage-video 语义配色）

| 色 | 色值 | 语义（严格按语义选色，不得随机） |
|---|---|---|
| 焦橙 | `#D2601A` | 时间消耗、成本、紧迫 |
| 芥末黄 | `#D9A425` | 工具、警示、经验流失 |
| 墨绿 | `#2F6B4F` | 认知、判断、系统复位 |

- 一个色不得成为通用色；同一批镜头内轮换主导色系。

- 禁止渐变作为主背景；渐变仅允许出现在纸面纤维质感的极轻微明暗上。

## 3. 字体（Typography）

### 3.1 字幕（实测最严格的一项，151 帧统计 p10 = p90 = 26px）

| 项 | 原生（1280×720） | **1920×1080 等效** |
|---|---:|---:|
| 字幕块高 | **26px** | **39px** |
| 推断 font-size | 24–26px | **36–39px** |
| 字幕底边 y | 670 | 1005 |
| 距画面底 | **49px** | **74px** |
| 水平中心 x | 639（画面中心 640，误差 1px） | 960 |

- 字体：思源黑体 / Noto Sans SC **Bold**
- 描边：黑色 2px（原生）/ 3px（1920），外发光禁止
- 对齐：**严格水平居中**
- 单行，超长则按语义断句换镜，不换行

> ⚠️ **历史错误记录**：前一版字幕高 138px，超标 **3.5 倍**。修正系数 = 39 / 138 ≈ **0.28**。这是用户反馈"字体太大"的唯一根因。

### 3.2 B-roll 文字层级（1920 基准）

| 层级 | 字号 | 字重 | 用途 |
|---|---:|---|---|
| Hero 大字 | 96–120px | Black | `broll-hero.big-type` 章节封面 |
| Hero 数字 | 140–180px | Black | `broll-hero.big-number` |
| 卡片标题 | 40–48px | Bold | 概念卡 / 流程节点 |
| 卡片正文 | 26–30px | Regular | 定义、说明 |
| 标签 / 来源 | 20–22px | Medium，字距 +0.08em，全大写 | SOURCE / FINDING |

**禁止**：em dash（—）作为装饰性分隔；表情符号；4 种以上字号同屏。

## 4. 背景与材质（Background & Material）

### 4.1 纸质拼贴材质配方（参考视频"高级感"的物理来源）

1. **平涂色场**：大面积单一实色纸面，不是渐变
2. **半调网点**（halftone dots）：可见的印刷网点，用于黑白照片剪影
3. **机切边缘**（crisp machine-cut edges）：硬朗直边，非柔化羽化
4. **暖奶油细描边**（thin warm-cream keyline）：纸片边缘极细亮线
5. **未涂布纸纤维**（uncoated paper fiber）：细微颗粒噪点
6. **真实物理阴影**：见第 5 节的非对称阴影

### 4.2 画框系统（**两套，不是一套** — 实测关键发现）

参考视频对数字人框与 B-roll 框使用**完全不同**的边框语言。混用会立刻显得廉价。

#### A. 数字人框（左栏 / 全宽 A-roll）

| 项 | 原生 | 1920 等效 |
|---|---|---|
| 内边框 | **6px 纯白**（实测 y=31..36 值 248–255） | 9px |
| 左外阴影 | 16px 宽，最深 −17 | 24px |
| 右侧 | **无可见白边**（但右方仍有 26px 空隙，**不与 B 框相接**） | — |
| 圆角 | 约 6px | 9px |
| 窄框宽度 | **392px = 30.63% 画面宽** | 588px |

#### B. B-roll 框（右栏 / 全宽信息层）

| 项 | 原生 | 1920 等效 |
|---|---|---|
| 边框 | **仅 2px 黑色细边**（实测值 4–10），**无白边** | 3px |
| 右外阴影 | 34px 宽，最深 −39 | 51px |
| 上边框 | 2px 黑边，起始 y≈39（比左框 y=31 **低 8px**） | — |

### 4.2b SPLIT 精确几何 ★（本项曾出错，导致两框叠压）

溯源 `_geom2.log`，7 帧（t=14/16/32/62/104/120/205s）**零离散**：
原生 A 框 `[16,31]-[407,623]`，B 框 `[434,39]-[1245,615]`。

| 项 | 原生 | 1920 令牌 | 说明 |
|---|---:|---:|---|
| A 框 left | 16 | `24px` | **不贴边** |
| A 框 top / bottom | 31 / 96 | `46 / 144px` | |
| A 框 width | 392 | `588px` | 30.63% |
| **中缝 gutter** | **26** | **`39px`** | ★ 两框之间的空隙 |
| B 框 left | 434 | `651px` | = 24 + 588 + 39 |
| B 框 top / bottom | 39 / 104 | `58 / 156px` | 顶底各比 A 错位 12px |
| B 框 width | 812 | `1218px` | 63.44% |
| B 框 right 留白 | 34 | `51px` | **不贴边** |

**三条铁律：**

1. **中缝 39px 必须可见。** A 框右外沿 x=612，B 框左外沿 x=651，中间是背景色空隙。
   两框相接或叠压 = 直接返工。
2. **禁止用百分比宽度定位。** 百分比相对 stage 计算，而 `padding`/`border` 在 box 外
   额外撑开，两边一起挤会把中缝吃光。必须写死像素 + `box-sizing: border-box`。
3. **A 框右阴影必须 ≤ 中缝。** 实测右阴影 34px 原生（51px 等效）会越过 39px 中缝糊到
   B 框上，视觉上重新变成"粘在一起"。SPLIT 中收窄至 **36px**，留 3px 余量。

> A、B 两框顶部与底部**各错位 12px，不是对齐的**——这是参考视频"看起来松弛"的隐形来源，
> 对齐反而会显得呆板。

### 4.3 阴影方向性（实测四边，**非对称是审美关键**）

| 方向 | 宽度（原生） | 最深值 | 1920 等效宽 |
|---|---:|---:|---:|
| 左 | 16px | −17 | 24px |
| **右** | 34px | **−39** | 51px（SPLIT 中 A 框收窄至 36px） |
| **下** | 32px | **−49（最深）** | 48px |
| 上 | **0px** | ≈0 | 0 |

> **推论：光源位于左上方。** 因此右侧与下方阴影厚重，顶部几乎无阴影。
> **铁律**：禁止使用 `box-shadow: 0 4px 12px rgba(0,0,0,.1)` 这类对称阴影 —— 它违背本片的光照物理，是"AI 味"的典型特征。
> 正确写法示例（1920 基准）：
> ```css
> box-shadow:
>   -24px 0 24px -8px rgba(60,44,24,.16),   /* 左，浅 */
>    51px 0 40px -6px rgba(60,44,24,.34),   /* 右，重 */
>    0 48px 44px -10px rgba(60,44,24,.42);  /* 下，最重 */
> ```

## 5. 留白与版式（Space & Layout）

### 5.1 两种主导布局（实测覆盖 95%）

| 布局 | 占比 | 段数 | 中位镜长 | 组件 ID（touge 词汇表） |
|---|---:|---:|---:|---|
| **SPLIT** 左人右板 | **50%** | 32 | 3.5s | `aroll-composite.left-anchor-dashboard` |
| **FULL** 全宽信息 | **45%** | 34 | 3.0s | `broll-*` 全屏 |
| WIDE / MULTI | 5% | 5 | 1–8s | 次要变体 |

**SPLIT 精确分栏**（实测，详见 §4.2b）：
`24px 边距 | A 框 588px | **中缝 39px** | B 框 1218px | 51px 边距` = 1920px。
中缝是**背景色可见空隙**，两框绝不相接。

### 5.2 数字人构图（用户要求 #1）

- **视觉重心必须落在框宽的 49.6%–53.5%**，即偏离中心 ≤ ±3.5%（实测参考视频如此）
- 裁剪流程：先检测人脸/前景质心 → 再按质心居中裁剪，**不是按原视频中心裁**
- 关键主体保持在中间 70% 区域内，保证后续裁切安全

### 5.3 留白纪律

- 一帧只保留 **一个主角**，主动留白
- **禁止任何画面空一大片**（用户要求 #2）：SPLIT 的右栏、FULL 的整幅都必须有内容
- **开场即有 B-roll**（用户要求 #2）：实测参考视频 t=3s 已是完整信息版式，不存在"只有数字人"的开场
- 卡片内边距：32–40px（1920）；卡片间距：24px

## 7. 动画节奏（Motion & Rhythm）

### 7.1 剪辑节奏（实测参考视频 71 段 / 309s）

| 项 | 实测值 | 本片目标（240.88s） |
|---|---|---|
| 布局段数 | 71 | **70–75 Scene** |
| 中位镜长 | 3.0–3.5s | 3.2s |
| 镜长范围 | 1–18s | 2–6s 为主，关键段可 6–8s |
| 布局交替 | SPLIT ↔ FULL 近乎 50:45 | 同 |

节奏类型：**Tutorial / Knowledge**（touge 规则），非短视频 Hook 型。

### 7.2 动效参数（Remotion）

```ts
// 标准入场：无弹跳、稳重
spring({ frame, fps, config: { damping: 100, mass: 1, stiffness: 100 },
         durationInFrames: 12 })          // 0.4s

// 位移/透明度：必须 clamp，禁止溢出
interpolate(frame, [0, 12], [0, 1], {
  easing: Easing.bezier(0.22, 1, 0.36, 1),   // ease-out 收尾克制
  extrapolateLeft: 'clamp', extrapolateRight: 'clamp',
})
```

| 动作 | 时长 | 曲线 |
|---|---:|---|
| 卡片入场 | 0.4s（12f） | `spring damping:100` |
| 文字逐行显现 | 每行 0.13s（4f）错开 | `Easing.out(cubic)` |
| 打字机 | 每字 2–3f | 线性 + 光标 15f 闪烁 |
| 图表生长 | 0.8s（24f） | `Easing.bezier(.22,1,.36,1)` |
| 数字滚动 | 0.9s（27f） | `spring damping:120` |

### 7.3 转场

- **默认硬切**（实测参考视频以硬切为主）
- `crossfade` 仅用于**语义章节之间**，不是每个小镜头
- `broll-hero.inversion-flash` 全片 ≤ 2 次，禁止连续，单次 ≤ 1s
- 禁止 shader 转场、禁止推拉摇移（**锁定机位**）

## 8. 必须做到（MUST）

1. 数字人**按前景质心居中**裁剪，偏差 ≤ ±3.5%
2. **开场 0s 起即有 B-roll**，任何时刻画面不留大片空白
3. 字幕 1920 下 **36–39px**，距底 74px，严格居中，白字黑边 3px
4. 数字人框 = **9px 白边 + 左浅右重下最重的非对称阴影**
5. B-roll 框 = **3px 黑细边，无白边**，右阴影 51px
6. B-roll 底色为 **暖米色系**（`#DFCDB4`–`#F4E7D6`），永不纯白
7. 阴影严格遵循**左上光源**，四边不等宽
8. 每镜锚定**一个** touge 组件 ID
9. 屏显文字**必须可溯源到 SCRIPT.srt**（当前镜 / 提炼 / 总结 / 相邻承接）
10. 图表数字必须来自 SRT 或提供的素材，**不得编造**
11. B-roll 形式在全片中至少覆盖 **5 种不同呈现方式**
12. 制作流程：**先 gpt-image-2.0 出图 → 再图生视频**（用户要求 #7）
13. SPLIT ↔ FULL 交替推进，避免数字人长期固定一处
14. 每帧强调色 ≤ 2 处
15. **SPLIT 中缝 39px 必须为可见空隙**；两框定位一律绝对像素 + `box-sizing: border-box`；
    A 框右阴影 ≤ 中缝（36px）

---

## 9. 绝不能出现（NEVER）

1. ❌ 纯白背景 / 纯白卡片底
2. ❌ 对称 box-shadow（违背左上光源）
3. ❌ 数字人框与 B-roll 框用同一套边框
4. ❌ 字幕大于 40px（1920 基准）
5. ❌ 开场只有数字人、画面空一大片
6. ❌ AI 紫/粉渐变、深色 mesh、玻璃拟态泛用
7. ❌ 把 demo HTML 里的示意文字（`Prompt`/`Preview`/`示例`/`待载入`/镜号）当作内容写进画面
8. ❌ 编造数据、编造 UI 状态、编造未在 SRT 出现的论断
9. ❌ 表情符号作图标；手绘 SVG 图标
10. ❌ 镜头运动（推拉摇移变焦）、morph、warp
11. ❌ 每个小镜头都加转场
12. ❌ 4 种以上字号同屏；em dash 作装饰
13. ❌ 空白视觉停留（无信息的纯过渡镜）
14. ❌ 无限循环装饰性微动画
15. ❌ **A-roll 与 B-roll 相接或叠压**（中缝被吃掉）
16. ❌ **用百分比宽度做 SPLIT 分栏**（padding/border 外撑会吃掉中缝）
17. ❌ **A 框 `left:0` 贴边**（实测 left=24px，不贴边）
18. ❌ A 框右阴影越过中缝糊到 B 框上
