## 一、视频规格

| 项 | 值 |
|---|---|
| 画幅 | 竖屏 `1080 x 1920` |
| 时长 | `55-70 秒` |
| 镜数 | `8-10 镜` |
| 节奏 | 信息型快节奏，单镜优先 `<10 秒` |
| 结构 | A+B / B-only 混合 |

---

## 二、镜头结构原则

### 2.1 镜型分配

- A+B 镜：数字人右下出镜 + 左侧或上方主卡
- B-only 镜：纯信息板、图表卡、流程卡、章节导航卡

建议比例：

- A+B 镜：`40%-50%`
- B-only 镜：`50%-60%`

### 2.2 单镜时长纪律

| 镜型 | 推荐时长 |
|---|---|
| 钩子镜 | `4-6 秒` |
| 功能解释镜 | `5-8 秒` |
| 流程镜 / 图表镜 | `6-9 秒` |
| 收束镜 | `4-6 秒` |

如果某镜接近 10 秒，必须保证：

- 主要元素已经稳定
- 只保留字幕推进、数字增长或轻高亮变化

## 三、镜头模板库

### T1 钩子标题镜

- 顶部章节条
- 大标题
- 单个主视觉卡
- 字幕条
- 左下笔记卡 + 右下数字人

主动作：

- 标题推入
- 高亮条扫过
- 主卡轻推入

### T2 三列能力卡

- 标题
- 三列卡片 stagger 进入
- 底部总结条
- 字幕条
- 右下数字人或导航卡

主动作：

- 三卡依次飞入
- 底部总结条延迟点亮

### T3 流程 / 连接器镜

- 标题
- 4 个步骤卡
- 箭头 / 连线逐步出现
- 字幕条
- 底部笔记卡

主动作：

- 流程线绘制
- 当前步骤高亮切换

### T4 图文组合镜

- 上图下卡 或 左图右文
- 图片走 MCP `gpt-image-2.0`
- 旁边配 2-3 条说明

主动作：

- 图片轻缩放推进
- 说明卡 stagger 进入

### T5 数据 / 对比镜

- 数据条或柱状图
- 核心数字高亮
- 结论条

主动作：

- 数值增长
- 柱条生长
- 当前结论点亮

### T6 收束镜

- 单结论卡
- 章节导航最后一项点亮
- 数字人补一句收尾

主动作：

- 结论卡定帧
- 导航点亮
- 关键词高亮扫入

## 五、动效清单

每镜至少从下面选 `1-2` 个主动作：

1. 标题上推入场
2. 高亮底条先出现，文字后出现
3. 卡片 stagger 入场
4. 柱状图 / 数字增长
5. 流程箭头绘制
6. 当前导航项点亮
7. 主卡轻微 2.5D 推进

不要一镜全用。

---

## 六、图片生成建议

需要图片的镜头优先是：

- 镜 04
- 镜 07

提示词方向：

- flat editorial infographic illustration
- thick black outline
- warm cream background
- neon lime highlight
- clean blocks and labels
- vertical mobile explainer style
