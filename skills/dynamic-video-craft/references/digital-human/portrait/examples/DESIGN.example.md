# DESIGN.example.md · 口播数字人 + 竖屏 + ABroll 示例

> 这是 `douyin-dh-vertical-abroll-video` 的示例配置文档。
> 目标不是当最终成稿直接复用，而是给这条 Skill 提供一份能落地的风格骨架。
> 画面参考：`../references/base-config/成品.base.mp4`

---

## 〇、本版本要点

| 维度 | 本示例要求 |
|---|---|
| 画幅 | 竖屏 `1080 x 1920` |
| 风格 | 暖米底、黑粗描边、大圆角、荧光绿高亮 |
| 结构 | 顶部章节条 + 中部大主卡 + 独立字幕条 + 底部 2:1 信息区 |
| 数字人 | 右下小窗，作为 A-roll 叙述锚点 |
| 图片 | 默认走 MCP `gpt-image-2.0` 生成，风格要和卡片系统统一 |
| 动效 | 文字、卡片、图表、导航高亮都必须有轻量动态，不做静态翻页 |

---

## 一、画布与坐标系

### 1.1 主画布

| 项 | 值 |
|---|---|
| 像素 | `1080 x 1920` |
| 安全区 | 左右各 `40px`，上 `120px`，下 `90px` |
| 基础节奏 | 每镜优先 `4-8 秒`，重信息镜 `6-10 秒` |
| 页面缩放预览 | demo 可用 `0.5` 缩放到 `540 x 960` |

### 1.2 五区结构

1. 顶部章节条：`y = 120 - 230`
2. 主卡区：`y = 270 - 1080`
3. 字幕条：`y = 1110 - 1270`
4. 底部信息区：`y = 1310 - 1780`
5. 页脚：`y = 1810 - 1860`

底部信息区建议采用：

- 左侧 `2/3`：笔记卡 / 要点卡 / 标签卡
- 右侧 `1/3`：数字人小窗或章节导航卡

## 二、颜色体系

### 2.1 基础色

| 变量 | 色值 | 用途 |
|---|---|---|
| `--bg-cream` | `#F5F3EA` | 页面背景主底色 |
| `--panel` | `#FFFFFF` | 卡片底色 |
| `--ink` | `#181818` | 主文字与描边 |
| `--muted` | `#7D7D7D` | 次级文字 |

### 2.2 强调色

| 变量 | 色值 | 用途 |
|---|---|---|
| `--lime` | `#C8FF37` | 主高亮、激活态、关键词底条 |
| `--coral` | `#FF6E4A` | 重点提醒、左侧装饰条 |
| `--sky` | `#84D8FF` | 数据卡、说明条、次级高亮 |
| `--violet` | `#B59BFF` | 辅助分组、次级卡片 |
| `--butter` | `#F4DE74` | 笔记涂抹底条 |

### 2.3 阴影规则

- 禁止模糊阴影
- 只允许：
  - 彩色偏移硬阴影
  - 黑色压边阴影

推荐写法：

```css
box-shadow: 8px 8px 0 var(--lime);
box-shadow: 8px 8px 0 var(--coral);
box-shadow: 0 4px 0 var(--ink);
```

## 三、字体规范

| 用途 | 建议字体 | 字号 |
|---|---|---|
| 主标题 | 黑体 / Source Han Sans Bold | `72-96px` |
| 副标题 | 黑体 SemiBold | `28-38px` |
| 卡片标题 | 黑体 Bold | `34-46px` |
| 正文 | 黑体 / Arial | `22-30px` |
| 字幕条 | 黑体 Bold | `34-44px` |
| NOTE 手写感 | 行楷 / 手写字体替代 | `28-40px` |

排版原则：

1. 标题必须短、狠、直接
2. 正文只辅助，不抢标题
3. 关键词高亮优先用底条，不要全句上色
4. 字幕单条尽量短，保证一眼读完

---

## 四、分区元素规范

### 4.1 顶部章节条

必须包含：

- 章节编号，如 `CH 01`
- 章节名称
- 时间码或页码
- 左侧激活点

视觉要求：

- 白底
- 黑粗边框
- 大圆角
- 内部左右对齐清晰

### 4.2 主卡区

主卡区承担本镜最重要信息。

优先使用的版式：

1. 标题 + 单个主视觉图
2. 标题 + 三列功能卡
3. 标题 + 左图右文
4. 标题 + 上图下卡
5. 标题 + 数据条 / 步骤卡 / 对比卡

### 4.3 字幕条

必须独立存在，不和主卡混排。

要求：

- 白底黑边
- 字体粗
- 关键词可用天蓝 / 荧光绿 / 暖黄底条高亮
- 句子控制在一眼可读长度

### 4.4 底部左侧笔记卡

用于强化：

- 当镜重点词
- 3 个以内标签
- 手写式结论
- 一到两条辅助解释

视觉要求：

- 白底
- 黑粗边框
- `NOTE 01 / NOTE 02` 式标记
- 荧光条涂抹感高亮

### 4.5 右侧区域

二选一：

1. **数字人小窗**
   - 右下稳定出镜
   - 作为 A-roll 叙述锚点
2. **章节导航卡**
   - 用于 B-only 镜
   - 当前章节必须点亮

## 五、图片与插画规范

### 5.1 图片来源

如果用户没有明确给图：

- 默认走 MCP 的 `gpt-image-2.0`

### 5.2 图片风格关键词

生成图时优先包含：

- flat editorial illustration
- thick black outline
- clean color blocks
- minimal infographic
- warm editorial palette
- high contrast but not glossy

### 5.3 图片位置

图片优先出现在：

1. 主卡上半区横幅
2. 左图右文左侧
3. 上图下卡上侧
4. 数据示意图居中区域

不允许：

- 把图当贴纸零碎塞满边角
- 图片和卡片风格不统一
- 把真实照片和扁平插画乱混

---

## 六、动效设计基线

每镜必须至少包含一个主动作。

推荐组合：

1. 标题从下向上轻推入
2. 关键词高亮条先扫入，再出文字
3. 卡片 stagger 进入
4. 图表从 0 增长到目标值
5. 章节导航当前项点亮
6. 主卡整体轻微 2.5D 推进

禁止：

- 所有元素同一时刻出现
- 夸张弹跳
- 大幅旋转
- 纯静态停留

---

## 七、验收铁律

1. 看起来必须像“编辑化信息板”，不是普通 PPT
2. 一眼能看出章节结构
3. 一眼能看出当前重点词
4. 数字人和 B-roll 关系明确
5. 图片风格必须统一
6. 每镜优先不超过 `10 秒`
7. 动效是辅助理解，不是抢戏
