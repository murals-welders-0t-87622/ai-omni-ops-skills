# 网页艺术指导转视频：方向、构图与视觉验收

配套原文：见 visual-design-source-index.md 的 Garden Skills，先读 web-design-engineer 主文、design-calibration、design-directions、failure-patterns、critique-guide、browser-acceptance；需要具体风格时阅读 style-recipes 索引及选定文件。原文属于网页/交互设计，以下是用于线性视频的制作要求。

## 视觉任务卡
先写观众、要理解的事实、观看环境、画幅、时长、品牌资产、素材和用户确定的视觉基准。区分新设计、延续、局部修复和整体重做；用户已确认设计时，人物、画幅、结构、颜色、动效、资产和时间轴属于受保护合同，后续逐项对照。不要把审美评价等同于功能正确，也不要把已渲染等同于实际观看。

从五个轴写出可观察的决策：构图变化、运动强度、每屏有用信息、图像/素材依赖、品牌一致性。各轴可分低中高，每个判断必须落到具体镜头；高密度+高运动时让图表/信息成为焦点，背景和其他层减速；高原创+高密度时保持网格、字幕和事实位置稳定；高素材依赖时先确认真实资产、比例和权利，不用占位 CSS 伪造产品。不能为填满画面堆砌装饰。

## 方向与逐镜构图
写出独特的视觉概念、主要构图、色彩角色、字体角色、材质与摄影方式、动态词汇、禁止事项，以及适合内容的原因。至少设计代表性起点、中段事实画面和结尾作为相互有关但不重复的视觉系统；用户要求多方向才额外交多个方向。通过新闻事件、产品结构、数据、物件或动作寻找视觉隐喻。不要根据行业硬套色板，不虚构 logo、品牌界面或数据。

镜头表记录主句与信息任务、焦点对象、图片区域与裁切、信息层级、动线、构图、动作、证据与来源、出入转场、字幕、平台安全区以及预计停留。逐镜原创不意味着每镜随机换皮：比较邻镜的主体、构图、比例、画面重心、背景和信息表现，杜绝仅换文字、颜色或左右镜像。允许同一结构承担连续解释，但用户明确禁止重复时按其要求逐镜重构。

画面结构按叙事选择：大图与精确题注、对象特写与标注、编辑式图文、纵向故事、时间轴、尺度对照、证据截图、数字演算、带坐标的流程、交叉分屏、报告剖面、真实界面与局部放大、访谈人物与证据叠层。每种要说清它比普通文字卡片更能解释什么；禁止只凭装饰证明“丰富”。

## 静态层次与文字
先关闭动效审视关键帧：第一眼识别主体与事件，第二眼读出关系，最后找到来源与边界。字体先核中文覆盖、字重与字形授权，再测换行、字距、数字对齐、长标题、极短字幕与小屏读数。图片、标题、字幕和真实标注在不同安全层；背景亮暗必须随图像局部验证，避免文字被吞没。排版风格支持安静留白，也必须防止缺主体、空容器与信息孤岛。不能把每一条内容都放进同一种圆角卡。

图片先按最终显示窗口、焦点和运动方向确定宽高；主对象靠近裁切边缘时预留运动余量。真实截图保持比例，先验证可读与出处；生成图不冒充现场，字错重排或重制。若长宽比不匹配，按主题重新生成、扩图或重构布局；不无说明地拉伸，不能用双侧空白掩盖错误尺寸。

## 视觉审查
分别从方向一致、视觉层级、细节与对齐、可读与实际功能、原创性五方面逐项找问题，记录具体镜号和修复办法。优先修事实/错字、缺素材/脸部遮挡、严重裁切和对比，再修节奏、字体微调、装饰。把无效装饰、伪造数据、反复小眉题、重复左右分栏、过度卡片、无意义英文、只靠颜色区分的数据和重复表演型运动作为缺陷候选；品牌或内容确需时记录理由。

检查入场前、主体落定、信息变化、出场和邻接镜头。手机预览看关键字、字幕、图表数字、出处；逐段看人物、遮挡、字幕与音画，执行用户要求的检查次数并分别记录可观察证据。浏览器、媒体解码和渲染日志异常要归类，不能靠一个静帧称全片动态合格。
