# Remotion、代码绘制与生成素材的衔接

当前工程已经支持Remotion。先复用assets/remotion-starter和工程/时间轴规范，再按具体镜头添加Canvas、SVG、Three.js、数据、真实录屏或生成素材；不另起一个脱离品牌/脚本的生成流水线。

## 帧与时钟

按Composition真实fps计算秒；Sequence里的useCurrentFrame是局部帧，需要全片时间时显式加其from。字幕、声效与世界标注必须明确使用绝对或局部时间。参考 [useCurrentFrame官方说明](https://www.remotion.dev/docs/use-current-frame) 和 [确定性random](https://www.remotion.dev/docs/random)；实际API与媒体trim字段按当前固定版本核实，不抄旧startFrom/trimBefore差异。

有转场重叠时，分别记录镜头开始的理论秒数、实际量化帧和提前/延后帧，检查音画锚点使用同一时间基；以秒转帧取整会引入帧量化偏差，不能把理论时间当成每个导出帧的准确时间。依当前 fps 和实际输出核对接缝及首尾帧。

叠化时检查两层画面和底色的实际合成：上下两层同时半透明可能露出底色，造成闪白或亮度变化，即使两层透明度数值相加为一也不保证视觉正确。若需要连续不露底，选用适合当前合成顺序的混合方式并在不同背景上抽帧；有意露底时以分镜意图为准。缩放、平移或模糊还应检查边缘是否露底，不能只看静止首尾帧。

复用镜头运动、淡化或闪光组件前，检查时长与帧数为有效正数、关键帧时间单调，以及入场提前帧和退场重叠没有超出片段；零时长需明确静态或即时切换分支，避免除零或无效插值。背景色温、光晕与暗角变化应检查实际颜色和透明度的接点，分辨突变是否为有意设计，不把持续运动作为所有视频的默认要求。

移植镜头时检查源码实际使用的帧率、画布尺寸、素材循环与静音行为，不只依赖说明文档或示例组件的 `meta`。若渲染工程帧率不同，重新按当前 Composition 换算并核对关键事件；循环和静音是否适合真实人物口播要结合音轨、片长和口型逐段验证。

改编多行文字动画时，同时检查组件是否硬编码行数、事件延迟和文字尺寸：增删行后，依据实际最后一行的出现与停留时间重算高亮、转场和总时长。说明文档、示例与源码若来自不同版本，以实际使用的实现和输出核验；重播和跳帧渲染也需验证初态不会提前露出强调效果。

复用自定义弹簧时，区分欠阻尼、临界阻尼与过阻尼解并核算所选参数；临界阻尼的公式不能直接替代所有过阻尼情况。改变帧率、质量、阻尼或刚度时，以对应实现、边界条件及实际帧输出验证运动曲线，不把某组参数的观感推广为普遍规律。

Canvas用传入时间重画，不依赖前帧笔触累积；需要“已经写到哪里”时由完整路径及当前进度重构。Three.js的场景、相机、光、标注和shader uniforms由同一时间求值。随机布局按对象和固定种子，不能每次调用Math.random重新散布。相同帧乱序渲染和seek后应相同。

长时间展示页面可用微幅旋转或景深变化保持视觉节奏，但文字可读性和具体品牌需求优先。两轴同频且相位差适当时可以形成闭合轨迹；不同频率不必然永不重复，有理周期比可能在多个周期后重复。需要无缝循环时检查所有运动通道的首尾状态及速度，并在实际帧率下播放接缝。先核示例是否在一次运动后钳制停住，不能仅凭说明认定能持续运动。

手绘画线和笔尖需按同一路径及进度定位；导入 SVG 前确认实际实现支持路径命令，校验非零长度、起点与终点并抽查弯曲段。某旧示例的采样仅处理大写 M/L/Q，三次贝塞尔 C 可能被忽略；复杂路径应使用支持该路径的解析与测量方式，不能仅以原示例正常编译判定路径正确。

运动模糊可作为视觉设计参数，不必声称物理精确；若要随速度变化，按所用缓动曲线的导数或相邻帧位移计算，并在目标帧率、尺寸及渲染器中检查。旧示例的五次缓动使用 `(1-p)^0.75` 是视觉近似，不能等同该曲线的精确速度衰减。

## 声音与媒体

完整旁白通常在根时间线上只放一次；片段配音明确裁切和偏移，不每镜从原音轨开头重放。保留真实句尾与足够画面，不能为了定长截断最后一句。数字人画面与独立旁白组合时核源音轨是否重复混入；如实际需要去音，保留原片并生成可追溯无音副本，不默认丢所有原声。

数字人合成前先核原片的画幅、实际时长、口型和音轨；短于解说时调整镜头或补足可用素材，不能让最后一帧无提示地冒充人物继续说话。透明背景素材先在目标播放器和最终渲染链实测透明边缘与解码，不能仅凭扩展名、编码名称或一次元数据推断可用；绿幕抠像需抽查头发、手势和边缘。不同源帧率、合成fps和裁切点分别登记，具体trim语义以当前版本API为准，用已知时间点画面核对而非套用旧公式。

字体/图片/音频/视频先就绪，预演和渲染使用同一版文件。不要在逐帧过程中联网拿字体、生成配音或改变数据。检测中文缺字、文字宽高、祖先裁剪、遮挡与转场两侧，不只用像素外边界推断无裁剪；DOM命中测试不等于绘制顺序，具体遮挡需结合层级/透明度与实看。

## 分段拼接与重做范围

数字人、讲解画面和配音按分镜建立素材依赖清单：记录每段使用的源文件及版本、裁切、速度、转场和最终位置。拼接时字幕依据各段在最终时间轴上的实际起止位置重新计算；有裁切、加速、叠化或重叠时不能简单累加原音频时长。核对每个接缝及最后一句、尾音，保留未烧录字幕文件。

给卡片或转场配置音效时，记录动作时刻、素材、音量、裁切和实际时间基；镜头重排、变速或剪辑后同步更新声音事件。先检查音频文件是否存在且解码就绪，预览中的浏览器播放权限、异步解码和跨页面转发都可能导致缺音或延迟；不得凭定时重试间隔推断实际延迟上限。重新从已就绪素材生成音轨后检查最终成片的对应重音，而不是只看预览成功。采样、合成音与第三方内嵌资源分别核来源、许可及分发条件；示例里的授权声明不能替代对实际素材的核验。

音频以 Base64 内嵌在脚本中仍是分发素材；列出实际音频项及其来源，逐项对照授权记录和当前版本，新增项或来源清单缺失时保持许可未核。脚本通过语法检查、资源可解码或通用许可声明，均不能证明每条音效已获商用或再分发许可。

横向甩镜可在两个并列画面之间通过同方向运动、交叠和缓停建立连续感；依叙事、画幅和观感选强度，不必每处都使用。换方向时同时核出入画运动，放大或位移时检查边缘是否露底。源码使用普通 CSS 模糊不代表真实方向模糊；若需要方向性效果，核对当前渲染实现并播放过渡片段。

素材、画面或时间发生修订时，根据依赖关系重渲受影响片段和最终合成，检查相邻接缝；无需无条件重做无关镜头。记录输入版本或内容哈希与输出关联，文件修改时间只能辅助排查，不能单独证明使用的是最新素材。保留旧输出以便对比和回退。异步生成尚未确认结果时先查询原任务及供应商状态，记录已知标识；日志仍在更新或进度固定都不足以单独证明任务健康或卡死，不因旧模板的固定等待时间而自动重提、取消或改动其他任务。

## 浏览器逐帧渲染排查

先核实际输出尺寸、viewport、设备像素比、裁切框与页面缩放；预览控件若会遮挡画面，按工程结构隐藏且保留运行依赖，再检查控制脚本与画面。逻辑坐标经缩放后应以真实变换矩阵或画面边界换算，不直接把 CSS 像素当最终视频坐标。

逐帧播放若入场后提前定格，检查分镜时长、动画时间线与逐帧取样的映射，确认是否为有意留白；需要继续运动时按内容设计可寻址的后续变化，而不是仅把时间线拉长或给所有画面强加抖动。修改页面脚本、CSS 后先做语法及计算样式检查，再用代表帧和连续片段验收，脚本成功不等于视觉正确。

## 3D、数据与真实证据

只是讲产品利益时，真实产品图＋清楚二维演示可能更合适；需要结构/空间才加3D。数据图先计算同范围JSON，数字、形状数量、比例与标注共用它。缺CAD时不从照片创造内部零件，缺实测不造尺寸；生成画面只作清楚标识的表现手段，不替代性能证据。

## 性能与Windows恢复

先短段、低预演分辨率和少并发，测真实帧耗时与内存再扩大。3D和shader可能触发软件渲染，记录后端而不是笼统说“用了显卡”。不把上游个例“着色器慢近7倍”当本机结论。

浏览器启动异常时先记录退出码、实际Remotion版本及输出文件，核当前CLI是否支持已有浏览器路径。只有当前版本支持才选系统浏览器。编码内存不足先降并发/编码线程、隔离复现，并验证文件视频流与解码。不得为成功而关闭Web安全、删掉真实媒体、全局静音或重启业务Docker/WSL；原WorkBuddy兜底仅借问题定位，不照搬其危险默认值。

## 交付与成本

遵从用户的脚本/预览/MP4终点。MCP付费生成参数与授权不被代码视频替代；商品详情页后续视频仍按既有流程询问和确认参数。Remotion引擎与字体、音乐、素材、TTS各自条件不同，运行前查[官方许可](https://www.remotion.dev/license)，不宣称全部商用免费。

交付工程、可重建依赖/锁文件、真实资产及CREDITS、适用事实出处、成片和必要字幕；说明实际做了哪些抽帧/解码/视听检查。批量模板先做一个代表项，再用不同内容/最长文案/横竖屏边界检验，避免只测演示值。

## 可复用辅助与验证

assets/frame-clock.mjs提供纯函数：局部/绝对时钟、秒到帧、进度、按风格抽帧、稳定对象随机值和二维世界投影。用于自定义代码镜头，可按项目复制；不替代Remotion API。运行 `node --test <本技能>/tests/frame-clock.test.mjs` 验时间映射、乱序求值、固定布局、相机标注和非法输入。它证明辅助函数行为，不证明整片Remotion/3D渲染或声音质量。
