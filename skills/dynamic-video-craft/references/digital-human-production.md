# 数字人口播共用制作与衔接

## 起点与材料
先核对本品牌、选题、受众、交付画幅/时长和已有脚本；脚本事实来自可追溯资料，数字人肖像及声音须有使用授权。没有现成音频时，依据用户选定的配音能力生成并试听；缺权限或素材只阻止依赖它的步骤。

## 配置和制作
制作 DESIGN.md（画幅、安全区、色彩、字体、人物位置、字幕及素材来源）、STORYBOARD.md（每镜起止、旁白、人物主/次/退出、信息画面、素材、动作、转场、字幕、音轨）和可观看 demo。预览与正式工程使用同一数据/组件；先向用户展示并取得确认，再产生付费素材或正式成片，已有对应版本的明确确认有效。

根据旁白真实时长确定各镜边界：原始旁白、口型视频与字幕共用时间轴；ASR/对齐仅给候选，逐段试听核对停顿、文字和口型。等分时间不能当成精确对齐。数字人分段时在句边切，保留片段顺序和任务回执；失败或提交结果不明先查询已有任务，避免重复扣费。

从品牌 MCP 实时查询数字人、图片和视频应用，按用户指定模型及当前 schema 逐项填真实文件、分辨率、比例、时长与费用；详见 [中台能力接力](../../brand-omni-growth-expert/references/mcp-production-capabilities.md)。应用不可用时不声称已生成，不静默换平台。

## 可用的原创 Remotion 起步工程
使用 [动态视频工程](../../dynamic-video-craft/SKILL.md) 初始化。src/video.json 的可选 hosts 数组每项包含 id、src、start、end、placement；src 为 public/ 内人物视频相对路径，placement 为 full、lower-left、lower-right。各段视频从自身第零帧开始；需截取不同位置时先在外部准备片段。人物视频默认静音，旁白使用 audio.voiceover，避免重复发声；完整录音可用音轨作主时间轴。画中画如需透明背景，必须提供实际带透明通道且渲染可用的视频，普通 MP4 不会自动抠像。人物覆盖于信息层之上、字幕之下；按实际画面调整代码/设计以免挡字。

检查 `python <dynamic-video-craft>/scripts/check_timeline.py <工程>/src/video.json --require-voiceover`，再 `npm run typecheck`、预览并播放短片和整片。验证人物、信息区、字幕、声音、口型、首尾和音画同步；结构校验不等于真实观看。最后输出工程、实际视频、素材/授权记录、时间轴及检查结果，按当前品牌中台真实能力归档并回读。

最小配置示例（只展示新增字段，其他项目仍按模板配置）：

```json
{
  "hosts": [
    {"id":"host-1", "src":"host-1.mp4", "start":0, "end":4, "placement":"full"},
    {"id":"host-2", "src":"host-2.mp4", "start":4, "end":8, "placement":"lower-right"}
  ],
  "audio": {"voiceover":{"src":"narration.wav", "volume":1}}
}
```

片段需要预先放在 `public/`，时长至少覆盖对应时间段；不同片段不重叠，目录之外的路径不会通过检查。显示全屏的人物会盖住该时间段的信息画面；角落画中画使用实际视频自身的背景或透明度，须检查遮挡。字幕显示在人物层之上。模板不自动裁切语音、生成配音或为画面腾位置，需要在本片工程中具体设计。

## 画面组织与制作检查

1. **人物主讲段**：开头、问题提出与结论可以让人物承担注意力；不要同时堆放长段文字。先测人物实际占位，再给标题、字幕和平台交互区域留空间。
2. **信息主讲段**：按内容选择可核实截图、数据图、实拍或图示；先设计观众看什么、何时读完，再安排图形进入和退出。用人物缩角或短暂退出给证据留空间。
3. **转场和节奏**：按照上下文关系选择切换、推入或淡入；每个元素有进场、阅读停留及离场，重要数字和结论应能在实际播放中读清。
4. **声音**：以一条确认的旁白为基准；人物素材默认静音。逐段比对口型、字幕起止和旁白停顿，音乐音量以不遮挡人声为准；不能仅凭静音画面确认声音。
5. **验收**：分别检查实际导出、首尾、字幕拼写、事实与来源、人物遮挡、手机阅读和相邻转场；已渲染的测试色块不是人物生成或数字人业务验收。

## 限制
本工程只提供基础人物视频叠加，不提供人物生成、自动抠像、自动配音、卡片库或自动口型校验；这些必须由实际可用工具完成。公开仓不打包原 talkcraft 素材、源码或原始完整专家文档；使用第三方资源前核对授权。
