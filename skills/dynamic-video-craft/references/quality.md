# 验收方法

验收围绕观众实际看见和听见的内容。先解决事实、缺素材、裁字、重叠、时序和音画错误，再处理质感；不为满足抽象指标而给静止图表硬加抖动。

## 渲染前

运行 `check_timeline.py`、TypeScript 编译，确认素材存在、时间范围正确、镜头连续、事件属于正确镜头、引用的锚点存在。核对真实旁白时长。检查脚本不会识别实际画面的布局、真实 ASR 精度或声音质量；这些不能仅凭 PASS 放行。

## 关键帧与运动段

每镜看信息落定的一帧，复杂镜头额外看入场中段。对转场、数字替换、人物换位看边界前后的小段视频；单帧无法证明没有抖动或闪烁。需要精确卡片复刻时将参考动态片段与本片并看，比较路径、停留、节奏、遮罩、方向和收尾，不只比较最终截图。

横竖屏分别核字号、边距和截图裁切，不能只改变 Composition 尺寸。核对姓名、单位、数值、来源行；避免一屏多个巨型数字争夺注意力。图片上的标注必须在移动后仍准确。

## 成片检查

```text
ffprobe -v error -show_entries format=duration:stream=codec_name,width,height,r_frame_rate -of json out/video.mp4
ffmpeg -i out/video.mp4 -vf "blackdetect=d=0.25:pix_th=0.10,freezedetect=n=-50dB:d=1" -an -f null -
ffmpeg -i out/video.mp4 -af volumedetect -vn -f null -
```

黑场与静止检测只是候选提示：设计过的黑底、Logo 停留、细微动效都可能被标记，应对照镜头表判断。还要确认首尾帧、总帧数、最后一句和音轨没有截断；音量统计不能证明语音清晰或音效可听。

至少实际播放代表性镜头和转场；在有音频播放能力时听开头、重音和结尾，检查配音误读、音乐掩蔽、音效落点与尾音。当前工具无法听音时如实记录该限制。

修改后只重验受影响的镜头及其接缝；全片时间或音轨变动时复查全片时序。交付只描述实际完成的验证，不沿用上游测试报告的结果。
