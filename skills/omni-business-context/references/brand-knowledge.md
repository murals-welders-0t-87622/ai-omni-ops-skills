# 品牌知识库的使用和维护

首次开展品牌工作，先用 MCP 读取身份。查找同一个稳定品牌 ID 的目录标记，再查用户指定的既有品牌根；多品牌共用工作空间时，各品牌独立建根。根已经可靠确定时由 Agent 自行建立缺少的目录。相同展示名不能用于合并品牌。调用相邻总统筹下的 `scripts/brand_workspace.py --brand-root <品牌根> --brand-id <当前品牌ID> init`。输出给用户知识库的可打开路径。再次运行会补齐缺项，旧资料和用户的自定义分类继续保留。

## 按业务问题取资料

品牌根下的业务目录用于项目与交付；“知识库”按同样业务树收录可复用证据。品牌增长有品牌、产品、IP、人力资产、市场和报告等分类。用户可直接将原文件放入相应目录并加建子目录。渠道运营资料、案例和执行反馈按具体渠道收录。跨多个板块的资料放一份主档，其他板块引用来源、版本与适用问题。

1. 把任务翻成一个可判定的问题。例如“这项交付承诺对谁成立，有哪个客户使用过”。先看本板块第一性原理和已确认品牌事实，再查产品、成交、客服或相关渠道的反证。品牌增长用用户上传的第一手资料，增长报告保留作者、版本与审核状态。
2. 本地用同一脚本 `search --area 品牌增长 --query 交付`，按路径、行号打开原文，核对原始措辞和适用时间。直接放入目录的文件也可被发现。基础搜索读取 UTF-8 文本、按名称找其他文件；二进制附件要实际打开或用已授权解析器核对。命中摘要不足以支持原理升级。
3. 用户材料、核实的外部来源、Agent 的经验观察可以随授权任务入库。先判断什么行动会用到这份材料，注明来源、日期、品牌、对象/范围、证据类型、版本、可见范围与不确定性。经验必须指向实际任务或结果；分析稿内部标清观察、推断与待验证项。保留不同结论与时效，不把旧文件就地改成新事实。
4. 使用 `add --area 品牌增长 --category 产品资料库/服务保障 --kind 用户资料 --file <文件> --origin <来源>` 可留原文件、字节摘要和来源回执。相同文件与相同来源可重试；内容变化保留新版本，来源不同分别留据。敏感信息按品牌和资料范围最小使用，Agent 不自行更改上传者的分享范围。
5. 中台有可用接口时，优先在品牌知识库列表中复用正确库，上传文档并登记文件，再回读库、文件、处理状态和实际内容。来源已有稳定中台对象时可保存引用与自写分析。仅登记文件名或外链不足以证明文件内容已可搜索。断线后先读回查重，本地文件、上传、入库、索引、经营采纳分别有据可查。
6. 原理文件夹保存随技能发布的版本快照。日常入库不能改写原理。Agent 发起修订须提交原文与拟改句、证据及反例、受影响对象和适用范围，取得用户对具体变更的允许再交维护技能。用户主动指定修订时直接执行该范围，记下用户决定；其中尚待验证的观点如实标注。新增资料、用户确认实验、采纳品牌偏好、修改通用原理分别记录。历史版本、相反证据和来源保留以便回溯。

## Windows 安装版的网页和 MCP

先发现当前品牌连接实际开放的动作。具备以下能力时，用户说「帮我看看上次试机学到了什么」，先用 `manage_brand_library` 的 `search_knowledge_evidence` 按业务问题查找。已知资料所在板块时指定对应库，其余情况可在当前品牌跨库查。用文件名、原文片段及该版文件 ID、段号、内容摘要说明依据。仅命中标题、原文已改或检索无结果时，说明还缺哪份依据。

新资料可用 `import_knowledge_directory_file` 保留原目录导入，再用 `read_knowledge_original` 校验具体文件。同名资料按文件 ID 区分。归档经验用 `record_knowledge_note`，写明来自哪次任务、观察到的结果、适用条件和原文引用。下次遇到相似问题先查经验，再核原文及适用条件。

Agent 提出品牌原理修订时，先用 `list_knowledge_notes` 查现行版本，附上一版、拟改内容、适用范围、反例和证据。用户在知识库网页审核具体版本，Agent 再读回生效状态。多个提议碰到同一原理时，以当前生效版本重新评估。通用技能的修订沿用技能维护流程。

需要工作区与中台双向归档时，取已登录安装版知识库里提供的工作区同步工具。核对品牌标记，预览待处理文件和需新增的库，按用户授权写入，检查新增、复用、取回、跳过及错误。原理版本快照保存历史，下次读取当前生效清单。旧版本缺少新动作时，使用已开放的库列表、单文件登记和正文详情，并标明本次能核实的范围。

## 任务结束

交代从哪里读到了什么、哪项决定因此变化、留下了什么可复用资料、下次在哪个条件下复查。若发现方向和可持续增长冲突，指出会损害哪个客户结果或成本指标，提出更合适的一步。客户留资、发布、调整价格、启动收费服务等仍按实际授权执行。
