# 07 发布承接、指标、复盘与经营记忆

## 1. 从制作接到经营

发布前核对当前获准修订、平台账号、标题/封面/字幕/链接、产品/SKU、服务条件、使用范围、承接负责人和可用入口。制作许可、内容认可、公开发布、主动联系客户、投流支出分别按真实授权执行，不通过“做好了”推断全部获批。

发布保存平台作品ID与本地内容/修订ID、发布时间、渠道、自然/付费、账号角色和活动/链接标识。一个内容跨平台或再剪需要不同发布记录，共同指向原内容关系。已有作品不因复盘重新发布。

咨询、表单、预约、试机、商机、订单和复购通过已有合法映射关联，保留去重规则、时间窗与来源置信。销售客服看到：用户场景、来自哪条内容、已经讲了什么、下一步期待、实际条款及不确定事实；不让客户再从头解释。

## 2. 指标按任务解释

| 指标层 | 回答 | 注意 |
|---|---|---|
| 分发/匹配 | 有没有触达可能需要的人 | 播放次数、观看人数和目标人群占比不同；目标人群不可测就写未知 |
| 观看体验 | 是否愿意继续、能否跟上 | 2/3/5秒口径因平台而异；完播受时长影响；不从公开互动倒推留存 |
| 内容互动 | 为什么赞、藏、评、转 | 娱乐、认同、以后再看、争议和购买问题分别编码 |
| 品牌与信任 | 是否更懂品牌、相信能力 | 用真实访问、搜索、回访、询问等观察，不捏造品牌提升 |
| 行动漏斗 | 看后是否进入有价值的下一步 | 点击、有效咨询、合格线索、预约到场、试用、订单分别统计 |
| 经营质量 | 增长是否值得且可持续 | 净收入/退款、毛利、获客成本、交付/售后、续约复购；没数据不计算 |

每条有一个主结果和少量解释性信号。流量片可以低直接成交但贡献发现；转化片可以低播放但产生高价值客户。二者比较时看各自任务，也看组合整体，不能为了“各有目标”豁免完全无品牌关联的流量。

## 3. 指标字典与分母

每个指标记录 `名称、来源、单位、计数/去重、分子、分母、窗口、自然/付费、数据时间、采集时间、缺失原因`。来源提供的现成率优先保留原口径，内部计算另命名。

- 内部点赞率示例=点赞次数/平台播放次数，只有这两个数属于相同范围和窗口才计算。它不是统一平台官方定义。
- 内部有效咨询率=可归因的去重有效咨询人数/约定的去重访问人数；只有播放次数时不要偷偷把分母换成人数，可另报“每千次播放有效咨询数”。
- 表单完成率=完成表单数/开始表单数，点击到提交是另一指标。
- 合格线索率=合格去重线索数/去重有效线索数，资格标准事前定义且可核。
- 试机到场率=实际到场或完成试机数/同批已确认预约数；跨周期迟到结果要回补对应批次。
- 成交与复购定义需由经营数据和时间窗约定；支付GMV、退款后净收入、利润和ROI不混用。

未知是null，真实0有完整数据来源；分母0时率为null并解释。累计快照取增量时处理重置/退款，不能把两次累计数相加。同一作品或线索跨分页、账号、渠道去重；汇总率通常用总分子/总分母，不无权重平均不同比例。

## 4. 比较与归因

控制平台、账号角色、受众、发布时间、观察窗口、作品时长、预算、季节/活动和数据完整度。对比刚发2小时与发布7天的累计数没有直接意义。竞品公开数据常缺曝光和成交，能观察什么就说什么。

优先看分布、中位数和系列整体，同时展示极端值；单条爆款不代表稳定能力。小样本只提出假设与下一实验，不强算显著性或规定“3天判生死”。自然流量顺序试发通常不是随机实验，结论写为观察关联，不能声称证明因果。

内容可能通过多次接触辅助成交。分别呈现平台直接归因、CRM/链接可追踪、客户自述、观察关联；不相加成为多份同一订单。时间窗、回补和去重优先复用现有系统，不擅自创造新归因模型。

## 5. 分层诊断树

1. **曝光低**：先核账号状态、数据窗口/完整度、分发与人群，再检选题需求、开头与画面。不能只凭播放低认定被限流。
2. **开头掉得快**：检查人群信号、第一眼理解、首句/首动作、声音起点、画质与承诺；保留必要条件，不只变得更刺激。
3. **开头好、中段掉**：检查重复解释、信息负担、动作不推进、期待不兑现、声画错位。
4. **看完/互动好，匹配行为少**：检查吸引错人、品牌关系不清、只让观众看梗或收藏、缺可信证明。
5. **咨询多、有效少**：检查条件与人群、夸大承诺、入口引导、表单定义、销售分类；不能自动继续放大流量。
6. **有效线索多、成交弱**：与销售共同查价格/产品适配、响应、试用、决策链、服务能力，不把全责归于内容。
7. **成交好、退款/售后差**：优先纠正预期和交付，反馈回价值卡及产品/服务，必要时停止有误导的内容扩展。
8. **复购或使用弱**：查使用与维护内容、产品周期、需求变化及服务结果，低频采购不与快消同口径。

## 6. 改进实验卡

记录问题、可核观察、竞争解释、改哪个变量、保持什么、主指标与护栏、样本和窗口、预算/产能、停止/扩展条件、负责人、对应修订和结果。

例如：同一产品与后段演示，测试“直接结果”与“原创冲突”开头，优先看相同窗口的目标行为及开头留存，同时观察咨询是否更匹配。若两版同时换产品、声线、场景、时长与投放，不归因于单一钩子，只作为组合探索。

## 7. 经验沉淀分三级

- **本条修订**：如字幕太小、动作剪断、用户指定音色；只影响本产物。
- **品牌经验**：在某场景/客群/渠道下观察到的规律，记录证据、反例、样本、日期、有效范围和下次复查。
- **公共方法候选**：跨任务可复用且有充分证据的工艺或规则改善，经过新用例验证再发布技能版本。

不把一次人工纠偏后成功说成自主首轮通过；不把“短片只有18秒有播放”变为全部35秒上限；不把某个TTS故障变成永久禁用供应商。品牌事实、临时假设、创作偏好、实验结论和公共规则分别管理。

复盘交付用“结论→证据与口径→其他解释/限制→改哪层→下一行动与验证”写。向全域增长Agent回传新发现的痛点、异议、匹配用户、承诺风险与业务瓶颈；向销售/产品/交付回传对应问题，内容专家不擅自改价格、政策、广告或产品库。
