# 视频复刻与品牌改编

参考视频做本品牌版本时，先交付**多维拆解报告**，再依据品牌、产品和用户要求交付**复刻脚本、逐镜分镜及提示词**；用户要求成片则继续交接制作、实看验收和归档。用户只要求拆解或其他阶段时，在该终点交付。继续项目先读取已有版本与在途任务，不重复生成。

## 1. 找到原片和已有拆解

明确品牌、产品、参考视频、平台、用途、用户要求保留和替换的部分及授权范围；读取本品牌资料库中的产品事实、素材和目标受众，不借用其他品牌的资料。先按 [中台拆解衔接](references/mcp-handoff.md) 在当前品牌 MCP 查找对应视频与已有拆解，核对平台、作品、报告版本和素材快照；有可信报告时复用并补齐缺失维度，避免重复拆解。历史报告是待核对的证据，不等于本次已观看原片。

查看原视频的连续画面并试听音轨；按需要结合转写、关键帧、元数据，核实文字、动作和剪辑点。抽帧、元数据或转写不能代替实际观察动作或听声音。原片、音轨或部分时段不可用时，区分已观察、推断与未知，指出影响，不虚构细节。

## 2. 形成多维拆解报告

按照 [多维报告与分镜](references/analysis-and-storyboard.md) 分析用户目标与内容定位、开场、叙事与留存、画面和镜头、剪辑节奏、声音、情绪与转化、可迁移机制和边界；引用时间段与实际观察依据。中台已有分类时实时读取相应平台的拆解维度，逐项标记观察到、未发现、未知或不适用，不把“未知”视为不存在。重要动作需要记录起始、过程、结束或未完成状态，以及主体、物件、位置和遮挡变化。

报告先解释这条片子如何吸引人、讲述什么、如何转化，再列逐镜观察、值得借鉴的机制、品牌适配建议、证据和限制。没有可靠来源的数据、卖点和效果不得当事实写入。中台只接收与其真实对象、来源和任务相匹配的结果，接口和保存回读遵循衔接指南。

## 3. 改编成品牌视频方案

结合真实品牌定位、产品及用户要求，说明保留、替换、新增与不适用的部分，以及为什么有利于目标受众理解产品；不照搬未经授权的人物、声音、音乐、标识及素材。把经证据支持的卖点写成面向客户的利益表达，区分已核实、待核实，不能虚构功效。

输出完整脚本和逐镜表：原片证据时间、新片时长、镜头目的、画面主体与动作、空间位置、景别机位及运镜、台词字幕、声音、产品/SKU与素材、转场及连续性、制作方式和检查点。按实际动作与口播重新安排时间，不能机械套用原片秒数。多镜头人物、场景、物件需明确一致性和前后衔接；原片没拍到的部分作为设计，不冒充观察。

每个拟生成镜头分别给出首帧画面提示词和动作/运镜提示词，写清主体、环境、动作顺序、画风、构图、物件变化、时长与比例、必要约束和参考素材；按实际选择的模型和 API 输入能力适配，未知参数标待确认，禁止假定通用格式或上限。提供配音、字幕与音效的内容及时间关系；辨明原声能否使用，未经授权不用第三方音轨或克隆声音。

## 4. 用户需要成片时继续制作

按实际脚本交接 ai-commerce-video、brand-creative-video、dynamic-video-craft 等专业技能，以 creative-production-router 协调，指定一个成片负责人和时间轴。用户指定的模型与中台能力遵循 [中台制作能力](../brand-omni-growth-expert/references/mcp-production-capabilities.md)，实时核验当前品牌工具、模型、参数、权限与费用；不可用则说明，不悄悄替换。用户只要拆解与方案时不发起付费生成。

分镜与素材可复用；生成任务超时先查原作业，避免重复费用。实际观看成片并试听，检查动作连续性、产品一致、字幕、声画同步及用户要求；逐项说明通过、待修和未验。按 [本地建档标准](../brand-omni-growth-expert/references/local-archive-standard.md) 保存项目，按实时中台能力回写并回读，不能把方案或 job 当成成片。发布按当次授权处理。

来源及许可见 [复刻制作与检查](references/recreation-guide.md)。用户反馈与真实效果可交 omni-growth-learning 分析，待用户选择后开展经营实验；不以相似度或播放量保证结果。
