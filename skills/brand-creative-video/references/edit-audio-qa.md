# 剪辑、声音与验收

## 剪辑工程

剪辑段有源文件hash、入点/出点、目标时间、音轨选用和变速记录。先按故事因果拼出可懂的版本，再做节奏、音效、字幕、调色和品牌片尾。跨地点蒙太奇可以快，角色说话和观众理解的反应不能随意砍掉。

如果本机使用HyperFrames/Remotion或其他剪辑工具，按宿主对应现有技能执行其验证/渲染流程；本技能不伪造“已运行检查”。也可用已验证的FFmpeg工作流。LocalMiniDrama合成可参考完整源码，但软件串接成功不等于剧情和声音合格。

最后一条镜头缺失时，先解决缺失镜头，不能拿静图、黑屏、重复镜头补齐并称完整生成片。品牌落版本身是设计画面，属于正当的剪辑组成。

## 原生声音优先检查

保留供应商原视频与原音轨。先听它的对白、环境、配乐和动作声，再决定保留、局部降噪、重混或局部重配。不要默认将所有原音轨静音，也不要因为供应商“支持声音”就声称本片已有合格对白。

对白检查：角色是否说对台词、声线是否一致、语气像在场交流、停顿与表情是否自然、口型是否对齐、角色是否串词。猫叫是可选的短促动作声音，不代替中文叙事，更不循环铺满全片。

需要重配时先做关键台词试听，锁定表演再扩展，不先用一整段机器旁白覆盖角色表演。音效按事件发生，场景底噪随空间变；音乐不能盖住语言。音量、峰值与响度按目标平台及当前素材核实，不为“影视级”套用一个万能数字。

## 审核矩阵

| 级别 | 实际检查 |
|---|---|
| 母版/首帧 | 身份、服装、毛纹、人物数量、位置、场景和道具、品牌字样 |
| 生成片段 | 开始/结束状态、动作完成、物理接触、脸与手、遮挡后身份、说话者与声线、可剪区间 |
| 拼接 | 因果是否清楚、人物/物件/机位衔接、日夜变化、同镜音画同步、无意闪帧或停顿 |
| 成片 | 总时长/画幅/分辨率/fps/音轨、字幕可读、品牌片尾、全片完整解码、从头到尾视听 |

逐秒抽帧/contact sheet用于定位视觉问题，不冒充完整音频审听和运动观看。完整解码没有报错也不证明故事好看；都要各自记录。

## 问题如何返修

每项失败写清`shot_id / timecode / 实际观察 / 预期 / 最小修复 / 受影响依赖`。先分辨是母版、首帧、视频动作、对白、剪辑还是品牌字样问题。局部修复优先；确需重新调用时按已授权费用和重试范围执行。

## 最终交付

成片文件、可播放预览、剧本与分镜、资产/首帧/实际参考图映射、逐片段提示词、真实供应商任务与结果、剪辑时间线、声音选择、QA与剩余缺口。敏感原素材和密钥不进入公开包。

片长上限包括片尾；本样例目标28秒、上限30秒。实际输出若超长，优先修剪无关过渡，不能无说明快放人声。没有真实渲染文件就交“制作包”，不要叫“完整视频”。
