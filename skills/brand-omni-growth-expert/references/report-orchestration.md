# 品牌增长报告：分析、分工与交接

## 在什么情况下使用

用户需要完整品牌增长报告或重做品牌级策略时使用本流程；已批准方案的执行、单平台任务和持续增长计划按任务终点接续，不为套模板重新跑整份报告。先读当前品牌资料、产品、经营事实和已有报告，再选择相关领域技能和资料；未发现的材料明确记为缺口。资料的历史品牌专用规则不自动变成其他品牌的规则。

## 八类输入与判断

检查品牌基础、经营现状、产品交易、用户市场、公域、私域、资源约束、增长目标：标出来源、时间、适用品牌、已知事实、冲突和缺失。信息足够时完成完整分析；部分不足仍交可用方案，将受影响的结论与测算标记待验证；客户、产品或主要生意模式等关键对象无法判断时，先提出最少业务问题，不索要技术参数。不能把渠道、经营指标或增长成效补造出来。

## 报告最后要让人能作出哪些决定

- **老板定方向。** 第一页用本品牌自己的语言说清现阶段的目标客群和场景、用户尚未被满足的需求、产品靠什么机制兑现差异、企业希望用户用哪句话转述它、接下来优先增长什么。说明另一个可行方向为何排后，若判断错误，看什么事实会改判。
- **各负责人能开工。** 每条路径都写出它承接的产品判断、服务对象、当前瓶颈、负责人和首个动作、交给谁的具体产物、观察周期与经营口径。全局、品牌、公域、私域、电商、销售及交付逐项交代。对不适用或当前暂缓的板块，写业务理由及何时重启。
- **复盘时能决策。** 同时写清希望改变的用户认知或行为，以及预计怎样带来可持续的经营结果。把基线、建议目标、已确认目标和实际结果分开；对关键假设给出反例或停止条件。

### 把通用原理写成本品牌的产品原理

先用一小段文字讲“特定场景、特定人群对解决方案的集体共识”，随即用本品牌证据回答四个问题。顾客在什么限制下要完成什么事？现有替代办法在哪一步失效？我们的产品或服务靠哪一个具体设计改变结果？具备什么条件才兑现，在哪类客户或场景会失效？再写企业希望顾客形成什么认识、顾客目前实际怎么说，两者之差就是要解决的品牌问题。有多条产品线时，说明哪条先承接增长、其它产品如何配合，证据不足的产品判断明确列为假设。

### 用同一产品判断展开各业务板块

| 板块 | 报告必须回答的经营问题 | 可以交接的产物及观察口径 |
|---|---|---|
| 全局方向与资源 | 当前限制来自需求、认知、触达、交易还是履约？先投入哪项能力，暂缓什么？ | 老板确认的目标客群、周期、资源与扩量条件。财务复核整体贡献和交付容量 |
| 品牌、产品、IP与人员 | 目标共识要求改变哪项产品规格、服务承诺、库存或人员能力？谁有资格对外作证明？ | 可交付的产品方案、承诺范围、证明材料和负责人。以使用反馈、缺货、退换或失约检查兑现 |
| 公域获客 | 抖音或视频号如何演示机制，小红书搜索或公众号如何回答顾虑，GEO 如何呈现有依据的答案？全网线索、达人或投放在何时值得投入？ | 具体选题或用户问题、证据、目标触点、落地页或销售交接对象。分别看合格咨询、准确引用、成交贡献及获客成本 |
| 电商、门店与其他交易入口 | 货架、报价、规格选择、预约和履约方式怎样兑现购买理由？B2B 项目的成交若在线下发生，站内承担什么角色？ | 商品页、预约名额或试用申请及其承接人。看净支付、试用转单、退款和每单贡献，按实际生意选口径 |
| 私域复购 | 客户使用后还需要什么服务？哪种联系有助于持续获得价值并带来复购、续约或转介绍？ | 服务节点、会员触达或维保计划，交到对应负责人。按成熟客户队列看复购、续约、推荐与投诉 |
| 销售、客服与交付 | 谁决策、疑虑是什么、谁能承诺，成交后哪份验收记录能兑现同一个价值？ | 从有效需求到成交、交付及售后的交接记录。看有效商机转单、兑现率、流失原因与交付成本 |
| 全局复盘与下一轮 | 哪些行为显示共识正在改变？哪些增长可能由折扣、季节或订单迁移解释？哪项结论应回到品牌资料和下一轮设计？ | 去重后的整品牌数据、用户原话、替代解释和下期资源取舍，保留原方案和结论版本 |

### 案例和资料怎样进入正文

案例必须发生在真实企业或可追溯的实际项目中。优先在品牌 MCP 现有对标作品中提取有品牌、产品及动作的线索。仍缺合适案例时，按业务问题检索已授权的采集库或公开资料。用年报、原版产品资料、服务条款、企业产品档案或可定位的当事人原访谈核实。写清发生时间或资料适用期、出处、实际做法和可确认的结果。二手讲解单独署名。没有顾客原话、交易数字或结果的资料，就讲到可证实的那一步。不要编造受访者回答、门店、订单、利润、排名或转化率来补全章节。

从[案例与原始资料](growth-cases-and-sources.md)选择与当前经营决定最接近的一例。主案例参照[红罐王老吉五章实案](red-can-wanglaoji-growth-report.md)，先还原顾客原有行为和替代办法，再解释企业为此改变的产品、触点或合同，最后列出实际市场结果和同期其他变化。至少找一种能反驳当前判断的现场观察。若资料只有大销量，可用[瑞幸单品与同店对照](growth-report-worked-example.md)检查误归因，用更能说明机制的材料承担主案例。历史事实、作者判断、Agent 建议和品牌负责人亲自确认的决定各自署明。把正文里的品牌换成同行看看，若动作仍能原样照搬，就回到产品与履约资料重新推导。

## 经营推演与专业分工

做整品牌增长报告时，五章共同回答一个经营问题：希望哪群人在什么场景形成怎样的品牌共识，需要怎样的差异化产品和组织行动来兑现、传播并积累它。诊断章并列企业自述、用户真实看法和交付证据；机会章比较目标场景里的需求空白与差异化候选；营收章核各候选对客群规模、价格、履约成本与持续使用的影响；营销章明确标签、口碑来自哪里、先在哪个触点传播；优先级章记录老板选中的方向、资源取舍、负责人和复查周期。专项委托交对应部分，遵循[品牌增长原理](brand-growth-first-principles.md)。

1. 先说明谁有需求、有什么痛点、品牌靠什么产品和服务解决、替代方案是什么、差异化有什么证据，以及目前哪些渠道带来客户和收入。对照老板与各角色是否围绕同一增长方向工作，指出最主要的协同断点。
2. 按当前真实数据及业务模式拆解财务结果与驱动因素。以电商为例，同一范围和周期内，支付金额可按支付订单数×每单支付金额，或按去重支付买家数×每位买家支付金额推演；访客×访客支付转化率可估算买家数，须保持访客/买家的统计口径一致。复购体现为指定成熟队列的再次购买，既可能影响买家数，也可能影响购买次数和人均金额；不得无定义地把复购率再乘入已包含老客的支付金额。其他行业采用与其成交和交付方式匹配的指标模型。
3. 各相关领域以实际技能完成分析：公域与 GEO 共用客群痛点、可信证据和内容资产，但各自验证渠道表现；电商承接商品交易；私域与销售分别设计客户生命周期、服务和成交接力；营收分析核对渠道贡献、预算、毛利和 ROI 口径。只有实际调用其他执行体才记录其参与，未调用则说明由当前 Codex 综合对应专业方法完成。
4. 根据实际业务周期制定分阶段目标、优先动作、资源和责任人，以及复盘指标；可使用季度路线，但不能强制所有任务采用一年周期。各动作说明预期改善什么指标、为什么有效、依据和依赖，保留假设和实际结果区别。
5. 完整报告依次覆盖品牌诊断、机会洞察、营收增长、营销策略、增长结论与优先级。每章至少回答结论、事实依据、问题机会和下一步，首屏优先展示老板需要决策的阶段重点、目标和动作。跨内容、搜索、电商、私域、销售与服务写清谁承接谁、客户反馈如何回流。

## 归档和下游接力

发现当前品牌可用的 MCP 工具及 schema，先完成报告正文，再按当前能力保存到品牌增长报告；回读品牌、正文、版本和状态。记录可供下游引用的报告或方案标识以及适用周期，后续内容、渠道、销售及复盘主动读取适用版本；没有可用写入或回读能力就交付本地可查看成果并标明待归档，不能声称已保存或已被其他模块使用。计划保存、负责人确认、外部执行与经营效果分别核验。
