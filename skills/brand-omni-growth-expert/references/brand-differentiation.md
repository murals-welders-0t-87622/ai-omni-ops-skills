# 从一次真实选择找到品牌增长的起点

客户在什么时候遇到了什么麻烦，当时还有哪些办法，为什么愿意付钱选你？在相近场景中，不同客户能独立说出相近的选择理由，并且产品或服务能反复兑现，品牌就具备了可积累的共识。继续增长还要检验每笔生意的贡献、交付容量、触达成本和回收周期。这是一套诊断方法，具体品牌的答案要从交易、客户语言与交付证据中取得。

## 把七个判断落到证据

| 判断 | 从哪件事查起 | 可推翻当前判断的迹象 |
|---|---|---|
| 需求发生的场景 | 还原购买前十分钟或立项前的触发事件，包括时间压力、地点、旧办法和失败代价 | 去掉场景描述，客户的选择完全相同 |
| 最先服务的人 | 指出具体使用者、付款者、采购决策者，分别问谁承担出错后果 | 浏览的人多，批准预算的人没有理由行动 |
| 解决方案 | 用同一任务让客户比较你、同行、自行处理和暂时不做，记录时间、风险、体验与总成本 | 新功能得到称赞，却无人用、试、付费或续用 |
| 可复述的标签 | 让客户离开产品页后用自己的话告诉同事“什么时候用、能解决什么” | 不同人只记得广告，没有记住场景或品牌 |
| 口碑 | 回读自发转介绍、投诉和退款中的原话，区分有奖推荐和主动推荐 | 承诺获得认同，交付后的真实评价却相反 |
| 留存与替换 | 找出持续使用后增加的便利、信任或协作价值，核查续用理由和退出反馈 | 只能依赖补贴、难以取消或人为设障留人 |
| 传播 | 找客户作决定的真实触点，使同一证据贯穿内容、货架、咨询、试用和售后 | 看过的人多，合格咨询、选择或复述没有变化 |

## 找到两个值得比较的差异化候选

- **先找需求空白。** 找最近的成交、流失、退货各一例。列出原先解决办法和仍要忍受的代价。市场上没人做只是线索，已有客户主动付出金钱、时间、风险或额外劳动来解决问题，证据更强。把反例和不服务的人一起写下。
- **新品先选市场位置。** 对标主流选择的主张、目标人、使用时刻和反复出现的负评。选一个重要且欠服务的场景，再定产品要求。已有产品优先检查服务、套装、保障、试用或交付方式。换说法之前先核能力能否兑现。
- **分清四种改法。** 功能改法要能演示结果；场景改法要改变至少一个产品或服务决策；认知改法让客户记得住并主动复述；交易改法降低试错或采购难度。情绪、审美、身份或社群也可构成价值，要有体验和付费行为支撑。短视频能拍出前后对照是一种证据，长周期采购可能更需要验收记录。
- **从购买者的视角做减法。** 把候选写成“当……时，……这类人用我们能……，依据是……”。删去客户不在意、同行同样能兑现或本方拿不出证据的主张。选一条口语化表达，再由陌生目标客户复述。复述正确能证明易懂，决定购买还需另验。
- **留出经济边界。** 把顾客愿意支付的代价、交付成本、售后负担和替代难度并列。单纯信息差容易消失；节省决策时间和长期信任要看是否持续。作品中关于溢价与品类依赖度的公式只作讨论线索，不据此计算利润或判断一个行业不能做品牌。

## 和老板一起做选择

每轮只追问最能改变判断的一两个问题。读过的资料先代为填写，标明来自哪里；每轮结束用老板和客户听得懂的话复述结论，邀请纠正。信息已经齐全可跳过对应轮次。

1. **还原一笔生意。** “最近一单，客户是在遇到什么事之后来找你？如果没有你，他原准备怎么办？”只回答“品质好”，就请对方讲一次可观察的验收或一次丢单。产出购买场景、角色、替代方案。
2. **找证据和边界。** “客户愿意为哪个环节付出额外代价？有没有一个人遇到同样问题却选了别人？”优先读报价、试用记录、评价、工单。只有内部说法时把答案写成假设，先去找能推翻它的材料。
3. **比较两条路。** 展示两个具体候选，分别写目标客群、会放弃的客户、兑现动作、证明材料、资源与利润约束。问“如果这周只能验证一条，你选哪一条，为什么？”若用户认为两个都偏，带着修正回到上一轮。
4. **从表达走到行动。** 请用户用自己的话讲一次“谁在什么时刻为什么选我们”，由 Agent 找出仍抽象的词。把选中的主张变成一个触点、一项交付调整和一个可观察结果。已有授权内执行运营单；新实验先由用户选择，记基线、分母、观察周期、停止条件。
5. **回看是否值得放大。** 同时比较客户能否复述、是否试用或购买、交付有无兑现、贡献是否改善。反向信号写回知识库并标清适用范围。必要时主动建议停掉无效投入，明确下一个更有价值的动作。

## 跨行业使用示例

以下是推演示例，不能写成客户事实。快消可对比同一货架上“看懂—试买—复购”的变化，扣除赠券与退货；门店可对比同一时段预约者到店及再访，核高峰服务容量。B2B 设备由操作员试用、采购比总成本、主管验收，分角色记录数据，跟踪合格试点转单及后续维保。订阅服务比较首次达到价值所需时间、次月留存与支持成本；经销商即使卖同款，也可用及时备货、选型、安装与售后响应创造可验证的差异。低频生意可看增购、续保和转介绍，指标窗口跟随真实购买周期。

最后交一页经营单，写清场景与客户原话、替代方案、候选及反例、选中理由、本周期实际动作与负责人、指标口径、风险和复查时间。保留老板未同意的判断，避免把建议写成决定。
