# 指标与证据

每项指标保留：店铺标识、平台、周期/日期、时区、粒度、维度、单位、字段原名、工具/参数摘要、来源回执及拉取时间。缺失=null，真实0才记0。返回百分数、比率、元/分/微元必须核对官方字段或跨接口证据，不能只看数字大小猜单位。

| 指标 | 计算与限制 |
|---|---|
| 支付金额 | 实际支付口径；下单未付、结算、确认收货均另列 |
| 支付买家/订单/件数 | 去重人数、父/子订单、商品件数不能互换 |
| 访客UV | 周期去重按原工具口径；日UV之和可能是人次，不能冒充周去重UV |
| 转化率 | 同周期/范围支付买家÷对应访客；分母0记不可算 |
| 客单价 | 同范围支付金额÷支付买家；不是每订单金额 |
| UV价值 | 同范围支付金额÷UV；跨渠道UV不可默认可加 |
| 退款比 | 本周期成功退款÷本周期支付只是流量比；不等于本周期订单队列最终退货率 |
| 净额 | 只有支付与退款匹配了主体、窗口/队列口径才相减；不能自动称财务净收入 |
| 广告ROAS | 归因成交金额÷广告消耗，注明归因窗/直接或间接/支付或确认收货/退款处理；不等于利润ROI |
| 盈亏平衡ROAS | 1÷广告前贡献毛利率。贡献收入减商品成本、平台扣点、履约、相关退款损耗等，广告费尚未扣；负毛利/缺成本不可算 |
| 广告成交占比 | 归因成交÷全店支付只是诊断比值，不证明剩余部分全部自然成交；归因可能重叠、滞后或回溯 |
| 环比 | 同长度/时区/完整性/口径比较；基期0不报无限增长 |

证据等级由实际来源决定，不由语言流畅度决定：

- 原生工具展开并看到本次入参/回执：可记“已观察工具回执”；仍要核对店铺/周期/测试标签。
- 只有千问或专家总结/JSON转述：记“客户端上报，原始回执待观察”，不直接升级为平台独立证据。
- 多接口一致增强可信度，不能证明绝无模拟数据；“模拟数据不会回溯修订”不成立。
- 固定测试店铺、占位值、空数组、未准入错误与真实经营0分别处理。

分析避免：把迷你详情UV占比直接称低质因果、把广告支出与归因营收差额称净亏损、把小样本高转化直接放大预算。每个判断给下一步查证，优先选择能区分几种解释的数据。
