# Codex 对话制作与内容修订

用户可以直接在 Codex 对话中说要为哪个产品制作或修改什么，也可以在中台选好项目、复制当前环节委托并粘贴到对话。建立项目、复制委托都不代表 Codex 已执行。不要调用页面绑定的本机执行器或创建 `commerce_request_detail_task`；中台保留既有任务记录、产品资料、项目版本和媒体引用。

先核对当前品牌和目标产品，读取 detail 工作区；已有项目沿用项目 ID、最新版本及用户要求，新项目只创建一次。检查是否有未结束的旧制作任务或供应商任务，若存在先查明结果，避免重复收费。以实时 MCP 能力和权限为准，使用本技能完成卖点、主图、商品文案、详情页和按需视频；每次保存后读回确认品牌、项目及版本。旧版材料和未选页面保留。

用户可在页面直接编辑并保存文案新版本，也可选择要修改的对象及页码，填写意见后复制到 Codex 对话。仅修改指定范围；图片修改先定位同品牌的原图及项目当前版本，核对真实可用的编辑能力和参考图输入格式后再执行。保留已成功项目，不因单页失败重做整套。原图不得使用任意跨品牌 URL；不能直接读取时按实时 MCP 和用户权限处理。

视频先完成创意与提示词，再让用户确认具体创意、应用、分辨率、比例和时长；确认后才调用可用视频能力。新创意需对应当前项目版本，旧视频保留；重新生成不等于逐帧无损编辑。模型任务不明或超时先查询原任务及账单，不擅自重提。

由 Codex 实际通过当前品牌 MCP 调用并逐项归档，核实画面真实可预览、视频可播放；服务返回成功、文件质量、用户认可及商家发布分别判断。完成后告知用户刷新详情页。工作区页面只交接或展示结果，不能假称复制委托就是正在制作；旧任务在途时不自行取消、不重复执行。
