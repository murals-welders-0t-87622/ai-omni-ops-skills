# 逐页文案与画面

根据用户《2生成详情页文字》《3生成详情页画面》整理。原稿烘焙/茶饮例子不构成当前商品的价格、产地、健康、销量、物流或评价证据。

## 建议十页结构

| 页 | 决策任务 | 文案与视觉要点 |
|---|---|---|
| 1 主视觉 | 快速理解产品与首要利益 | 产品名、核心主张、真实产品主体；原稿封面800×800/1:1，模型不支持精确尺寸时先按支持值生成并明确后期尺寸，不假报已达800 |
| 2 核心卖点 | 回答为什么选它 | 3—4利益短句与证据对应，避免堆参数 |
| 3 规格细节 | 确认买哪款 | 已核实尺寸、材质、SKU差别、多角度细节 |
| 4 材质工艺 | 建立信任 | 真实工艺/来源；证书原件引用，不能生成伪证书 |
| 5—6 使用场景 | 关联现实需求 | 两个有区分的实际场景，产品按真实用法展示 |
| 7—8 信任与疑问 | 消除犹豫 | 有授权评价则如实引用；无评价换成实物说明/FAQ，不生成假用户/星级/销量 |
| 9 售后物流 | 明确履约边界 | 商家实际政策及适用条件；未知留待补充，不默认7天/48小时 |
| 10 行动引导 | 帮助选择与购买 | 规格/搭配/店铺引导；优惠需当前真实有效，不编倒计时 |

可按品类合并/调整，不把食品示例强套医疗器械、日化或耐用品。详情图里的按钮只是画面文案，不能声称有可点击弹窗/支付功能。

每页输出标题、主/副标题、卖点短句、必要注释/行动点。图内原文用引号标注以便精准排版，且保存为 pages[i].copy。将产品依据存 evidence，避免生成图后找不回原文。

## 风格与逐页提示词

如果用户给参考图，提炼色彩、版式、留白、材质、文字层级及装饰元素的“风格档案”；不复制他牌商标/人物身份。无参考时结合品牌调性给一套统一方案。

每页 prompt 必含：页面目的、实际产品图引用与主体位置、背景与场景、整体色系、版式/留白、逐字图内文字、字号层级/对齐方式、图形/图标、比例尺寸和产品保真要求。每页内容有区别，色彩、字体和产品一致；不能只给第一页提示词却声称整套已生成。

原资料默认首图1:1，详情图后续比例由实际用途与用户要求确定并统一。不能无声改成第三方 Skill 的3:4默认；它仅提供方法参考，不替代本任务多元探索模型选择。

## 验收与修改

实际打开图片检查中文、错别字、文字溢出/遮挡、包装/Logo/结构、SKU、品牌色与依据。生成图里的细小文字不准时，使用可编辑文字层排版或单页重做，保留原图与版本。用户指出文字风险时按真实平台规范核实，不能声称存在万能“违禁词检测3.0 API”或自动合规认证。
