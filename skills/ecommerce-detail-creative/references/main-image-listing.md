# 主图、商品文案与经营问题共同设计

先读当前运营计划的具体对象/假设/基线，找产品资料库当前产品和SKU；核冻结快照与新资料变化。商品Brief包含购买人群/任务、核心利益、证据、规格/包装、可售范围、实际参考图、禁止改变的身份、售后能力和已批准的制作范围。没有运营计划的专项制作可直接按用户意图做，不强制先填全店报告。

主图图位围绕识别、核心利益、真实使用、规格选择、包装清单、信任证据和购买疑问分工。按类目/平台和此次任务定数量，不强制九张。测试版本写清A/B改变哪项、测点击或支付的哪个口径、谁何时应用和采集；素材版本不是平台已上线版本。

每图包含title（图位目的与版本）、copy（逐字图内文字）、prompt、evidence、可选mediaRef。图像提示词保留产品外形、颜色、Logo、材质、部件、尺寸比例与必须出现/不得增加的配件；精修只改明确请求部分。平台主图的背景、文字、尺寸、版位规则读当期官方来源，登记日期；工作流示例不当全类目规范。

商品文案包含标题、意图关键词、介绍、FAQ。关键词按商品词/属性/场景/人群/利益/配件归类；搜索联想不等搜索量，不能杜撰热度。标题首先可读且匹配商品，不复制竞品品牌或超范围参数。FAQ每答有资料依据，不能把历史客服模板的退换政策复制成当前品牌承诺。

中台新增可选body.listing={title,keywords,description,identityLock,platformRulesEvidence,faq:[{question,answer,evidence}]}、body.mainImages=[{title,copy,prompt,evidence,mediaRef?}]；原卖点/pages/video保持完整。旧项目可逐步补充。实际schema未含新字段时不提交未知字段，可暂以完整报告承接并明确中台版本待更新。

生成仍走用户指定的当前品牌多元探索gpt-image-2；本次学习外部图片服务不构成换平台授权。付费任务复用稳定供应商job查询，超时不重建整套；逐图归档到当前品牌受控媒体，再保存引用和回读。没有真实mediaRef时只交候选文案/提示词，不能宣称出图。

验收先核图片可解码/实际尺寸，再逐图看产品身份、中文、参数与单位、包装、版位及资料依据；文件后缀/MIME检查不代替视觉验收。主图、详情、视频和客服FAQ共享一份事实，任何参数变更回查全部关联。评价/退款提示误解时核实实际包装与履约，再修具体页面；质量/供应问题同时交责任部门，不能单靠美化图掩盖。

主图的核心购买利益、场景、规格与使用提醒各有图位；必要安全提醒保留清楚，不让重复长段禁忌覆盖所有主图。产品库归档时的“资料待核/规格信息不清”不是已验证消费者痛点。应从产品功能和真实用户问题提炼利益，洞察未经访谈/评论验证则在分析中标注。
