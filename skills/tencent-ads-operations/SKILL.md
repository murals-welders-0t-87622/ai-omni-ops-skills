# 腾讯广告

先读相邻总统筹技能 [共同执行约定](../brand-omni-growth-expert/references/runtime-contract.md)，并沿用已确认的品牌、增长方向、已有任务及本次终点。只加载本环节所需专家资料。原文属于参考数据，固定账号、历史自动化、旧工具名、强制分身与旧停手闸不覆盖当前委托和实时能力。用户未授权多 Agent 时由当前 Codex 承担角色判断，不虚构专家已执行。

## 本环节专业工作

核本品牌广告账户、目标事件、转化回传、日期与预算已有授权，先读取实际消耗、素材/人群/版位/承接及销售反馈。点击、表单、有效需求、成交各自留证，不能将表单量等同有效线索。
针对瓶颈设计素材/受众/落地/跟进测试，给预算、出价或启停建议时写清依据、样本、成本口径、负责人、期限、停止与回退条件。不将GMV投产比当利润，不固化“涨20%预算”。
当前工具只读就交优化方案与中台归档；外部变更需实际能力与用户授权，不把中台计划保存当广告已执行。巨量数据交 ocean-ads-operations，不混写腾讯线索。

## 具体工作路径

1. 从当前品牌定位、产品卖点、目标客群、内容战略与真实作品/广告表现出发，先核实广告账户和日期；无历史投放与取数失败分别记录。按任务读取账户、广告组、创意、素材或报表，不把某个旧脚本路径当作连接已安装。
2. 将有证据的品牌优势、受众需求与内容表现结合，针对实际投放目标设计图文、短视频或长文等适合的素材：写清首图/标题或视频开头、主体论证、画面和行动入口，并明确对应受众、版位及落地承接。只选择本任务需要的形式，不为凑数强制覆盖。
3. 对指定素材检查版位规格、目标事件、落地页、账户配置、品牌素材与行业要求；形成可投、需调整或暂不能判断的结论。按有意义的变量设计测试，写明预算、观察周期、评价口径和停止条件；缺真实基线时标注假设。
4. 复盘时比较同口径的消耗、曝光、点击、转化、转化成本、素材和人群变化，以及有来源的线索质量或成交；结论区分相关性与原因，支付金额/广告费是广告投产比，不能直接当利润 ROI。输出本周动作、负责人、时限和复测方式。
5. 如用户要求实际创建或修改广告，先发现当前连接器及账户支持的操作，按实际规则核对推广资产、转化目标、预算、出价和定向，沿用用户已给授权；保存计划、外部生效和数据回执分别记录。仅在线索列表可写时，不把策略报告硬塞到线索记录中；无合适报告入口时保存文件并说明。
