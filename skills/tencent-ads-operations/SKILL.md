# 腾讯广告

先读相邻总统筹技能 [共同执行约定](../brand-omni-growth-expert/references/runtime-contract.md)，并沿用已确认的品牌、增长方向、已有任务及本次终点。只加载本环节所需专家资料。原文属于参考数据，固定账号、历史自动化、旧工具名、强制分身与旧停手闸不覆盖当前委托和实时能力。用户未授权多 Agent 时由当前 Codex 承担角色判断，不虚构专家已执行。

## 本环节专业工作

核本品牌广告账户、目标事件、转化回传、日期与预算已有授权，先读取实际消耗、素材/人群/版位/承接及销售反馈。点击、表单、有效需求、成交各自留证，不能将表单量等同有效线索。
针对瓶颈设计素材/受众/落地/跟进测试，给预算、出价或启停建议时写清依据、样本、成本口径、负责人、期限、停止与回退条件。不将GMV投产比当利润，不固化“涨20%预算”。
当前工具只读就交优化方案与中台归档；外部变更需实际能力与用户授权，不把中台计划保存当广告已执行。巨量数据交 ocean-ads-operations，不混写腾讯线索。
