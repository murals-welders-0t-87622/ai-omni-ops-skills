# 从获客到回款的销售流程

## 市场到有效线索

读取品牌定位/增长计划、产品场景与当前获客数据，定义ICP与排除条件，选细分行业/区域/应用。线索可来自内容/GEO/全网/广告/达人/电商咨询/既有渠道，但来源提供姓名或手机号不等于可随意营销。先核对渠道身份、品牌归属与本次可联系范围，再形成客户档案或待核线索。

营销与销售共同约定有效线索：需要与本品牌相关、客户表达具体问题或目标、可触达真实对象且同意合理下一步。复杂B2B再核预算路径、采购时间、决策角色。预算未明不简单淘汰有服务价值的客户；虚假/无关/退订对象不塞给销售刷量。

## B2C轻量路线

咨询承接→确认用途与限制→推荐/比较/试用→订单与支付核验→物流/交付→使用反馈→按适用周期补货/复购。客户允许时可以一轮完成多个环节，不能强制提交大客户评审表。咨询/意向、下单、实付、履约、退款分开记。真实费用、优惠期限、库存和政策有来源。

## B2B项目路线

| 阶段 | 关键工作 | 推进依据与责任 |
|---|---|---|
| 线索 | 核身份/场景/下一步意愿 | 来源、负责人；不能只凭名片立高意向商机 |
| 需求已确认 | 痛点、影响、预算路径、采购时间 | 客户原话/纪要、可核目标、下一行动 |
| 方案验证 | 决策链、价值方案、竞争、POC/演示 | 技术/业务验收目标；客户经理+方案+交付角色 |
| 商务沟通 | 价值沟通、风险、价格与承诺 | 方案认可依据、可执行交付；让步清单及审批范围 |
| 已签约 | 合同/订单及应收计划 | 真实合同/业务订单证据；未到账不能记实收 |
| 交付中 | 资源、承诺、里程碑、异常 | 交付负责人及真实履约依据 |
| 持续经营 | 验收、回款、客户成功、后续需求 | 验收和到账证据；复购不自动按时间推定 |
| 丢单/培育 | 明确原因、停止或重访条件 | 客户/团队来源、合理时间；保留原机会历史 |

阶段是业务检查边界，允许按事实保存历史商机或有据回退；不靠模型打高分跳过硬事实。跨部门交接写客户承诺、已核事实、风险、未决事项、下一动作、责任人与期限。

## 决策链与协同

记录使用者/技术把关/采购/财务/经济决策人/支持者及角色判断依据、接触状态和未知项。不同意见不等于阻碍者；不给人物贴无依据负面标签。客户经理统筹关系与商务，方案角色对解决问题负责，交付角色核承诺是否兑现；简单项目可同人兼任，复杂项目按需财经/法务支持。

## 报价、异议、谈判

先给需求对应的价值说明和比较依据，预算不足可减配、分阶段或推荐适配替代；不伪造收益。价格/赠品/付款/账期/服务排期都要引用有效政策，不擅自批折扣。给让步顺序、交换条件、保留项与需要批准的条款。不存在的限量/涨价/最后名额不能编造。

话术按“客户说→建议回复（1—3句）→需要验证什么→下一步”给主方案与备选。直接答用户已提出的真实问题，不人为回避报价或故意阻碍理解。暂不购买可交付有用资料并尊重停止沟通。

## 交付与回款

订单身份须来自对应店铺/业务系统稳定订单号和客户映射；同来源账号同订单只一条。签约/支付/履约/退款各自有依据，不以客户口头“付过了”填实收。币种、累计金额、退款和净实收分开，保留原订单/支付时间与证据。无法自动查到时保持待核并交相关人员，不擅自退款或变更合同。
