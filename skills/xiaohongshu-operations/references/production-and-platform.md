# 小红书内容执行与中台对照

结合当前品牌、已有计划及用户交付要求推进，不因缺少上游方案重做用户已完成的阶段。调用前读取当前品牌和实时工具定义；下列历史工具名仅作能力发现线索，不保证当前客户端或品牌可用。

## 1. 策略与选题

- 按品牌与商品真实资料、账号现状和实际采集，判断用户需求、定位与现有内容表现。查小红书采集工作区和近期作品，数据不足时按行业、产品、场景或人群问题选择可用采集能力；缺失数据如实标明。
- 基于当前策略、日历、可追溯对标及用户反馈给出选题、人群、问题、切入角度、依据、形式及承接；检查近期历史避免机械重复。同一主题的有价值新角度不因固定天数一律禁止。
- 原创按任务选择知识解释、比较、避坑或场景等表达；二创先核参考素材的来源和使用范围，拆解表达机制，再结合品牌事实独立创作，不照搬原文或冒充实际体验。

## 2. 笔记与配图

- 结合用户目标写标题、正文和必要标签；核查事实与产品证据、平台适用要求、涉嫌夸大/未经证实的效果或身份。可用的合规检测工具只作辅助，不把词表通过当平台审核或法律结论；缺检测时明确未验证，不能说已通过。
- 优化语言自然度后重新检查事实和合规，避免修订引入新错误。字数和排版按当前平台、用户、内容和可用材料确定；历史资料中“正文不超过300字”与“建议600字以上”冲突，不作为统一硬规则。
- 需要图文时根据每张图的用途制定封面、内页文案、构图与生成提示词；保持产品外观、规格、包装和品牌标识真实，检查画面文字可读性和裁切。尺寸、张数以本次要求和实时平台规范为准。
- 用户指定图片生成通过本品牌**多元探索平台 `gpt-image-2`**。从当前 `get_design_workspace_options` 等实时能力中发现模型选择项，再按当前 `create_design_work` schema 调用；检查真实作业状态、转存与可预览结果。无法使用时报告原因，不静默更换平台或用占位图充当生成图；用户另行指定其他平台时按授权执行。

## 3. 归档、发布与复盘

- 按用户已有品牌档案和本地建档标准保存选题、文案及实际图片。2026-10一次本机品牌工具目录可见 `create_ai_control_center_daily_plan` / `get_ai_control_center_daily_plans` 和 `create_ai_control_center_creative_material` / `get_ai_control_center_creative_materials`；旧资料中的 `create_openclaw_daily_plan`、`create_openclaw_creative_material` 在该连接中不可见。先查看当前连接schema及品牌权限，用真实入口保存并回读，其他品牌和版本仍需自行发现。
- `create_xiaohongshu_original_note` 和 `create_xiaohongshu_rewrite_note` 是发起对应创作生成任务的入口，不是纯保存既有成品；即使提供正文也可能继续触发配图生成。不能为了归档而重复调用它们；真实生成与费用按用户委托执行。已有成品的作品列表入库路径如实时能力未证实，明确保留缺口，不冒称已写入。
- 用户只要创作或审阅，不自动发布；有发布委托时交 content-distribution，区分保存草稿、平台受理和实际公开。
- 以相同时间窗口和真实作品数据观察曝光、点击、互动与承接；数据缺失不填0，分析假设和可验证动作，必要时交 omni-growth-learning，新的经营实验按用户选择执行。
