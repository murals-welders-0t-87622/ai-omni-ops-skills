# 中台接力：先发现实时能力再操作

以下只记录 2026-10-27 已核的独立 Lab 源码定义，不证明任意当前品牌令牌拥有工具、所有数据齐全或原生客户端已加载；运行时先读当前 `tools/list`、鉴权品牌与各工具 schema，按返回数据验证。未取得品牌授权时不查询/写入其他品牌。

- `get_xiaohongshu_collection_workspace` 的源码描述涵盖品牌/竞品账号、品牌/对标作品、搜索笔记和目标用户，列表 `limit` 有上限；是否包含特定数据、完整分页及真实口径以实际返回为准。已有数据先读，新增采集可能产生外部请求/费用，应检查实时能力和用户委托范围。
- `get_douyin_collection_workspace` 的源码描述是抖音采集工作区摘要，且特别提及达人搜索、结果池和联系摘要；不能只因名字就断言含全部作品、留存或转化。结合实际返回发现其他作品/统计工具，缺失则保留未知；视频号与抖音口径不擅自混合。
- `get_ai_control_center_strategy_optimizations` 可读取 brand_growth、xiaohongshu、douyin、wechat 范围的已有优化记录；在**当前工具实际提供且有相应权限**时，可将候选写入对应范围的 `create_ai_control_center_strategy_optimization`，使用标题与内容记录候选ID、来源、用户选择和复测条件，再读回。当前源码是文本记录、更新可覆盖、列表数量有限，不能假称原生结构化状态机、不可变版本、幂等或实时自动跟踪已存在。保留原记录，新结论可作为关联的新记录；不能用该工具保存所有私域/电商状态或品牌调查卡。
- 其他领域查当前合法 schema 和已有任务/行动记录；若没有合适对象，把台账留本品牌私有工作区并明确未回写。不要修改中台 schema 或编造任务来制造闭环；真正需要新增字段、自动采集、提醒或版本治理时，附真实证据形成系统改进候选，等用户选择实施。
- 任务中读取事实、准备候选与报告属于现有授权范围内的工作；执行具体实验、发布、预算或其他实际业务改变按用户选择及现有授权推进。保存候选不代表用户批准或业务已执行。

参照本次只读源码：`apps/server/src/modules/openclaw/openclaw.service.ts` 中相关工具定义、`openclaw-strategy-optimization.service.ts` 的存储模型。本技能安装没有改变中台或其连接器；是否能调用需在实际品牌另验。
