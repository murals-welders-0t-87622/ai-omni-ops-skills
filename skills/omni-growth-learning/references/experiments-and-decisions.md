# 从假设到可复用结论

1. 明确具体问题与真实对象、版本、观察窗、目标客户、主指标及分母、原始样本、历史可比期和目标含义；记录当前动作是否真的执行。提出要改变的一个主要因素、机制、预期方向、至少一个竞争解释和可反驳观察。
2. 优先真正随机、稳定的A/B分流：明确随机单位、人群、分配比例、控制组/变体、隔离及避免干扰、平台实现和实际样本；固定关键条件并记录执行回执。目标/护栏/观察期和费用事先确定；样本量根据基线、最小有意义差异、统计功效、资源/成熟窗口计算或说明无法计算。不得硬套固定天数、固定百分比或过早根据短暂波动判胜。
3. 如果平台无法随机分流，采用匹配作品、分时顺序或多次重复观察，并明确算法分发/时段/人群/季节/内容差异等混杂；标记为探索观察，不叫受控A/B或证明原因。小样本可做定性访谈/作品对照并留复测条件；不要为了显著性虚增样本。
4. 实验主指标可为适配的观看/匹配咨询/支付/复购等；同时设置品牌相关性、真实承诺、负反馈、退款、成本等合适护栏。效果方向和范围是预测；无依据不得承诺数值。明确谁执行、需要什么材料/预算/权限、何时读取什么报表、何时调整或停止。
5. 有随机分流时检查分组是否按预设比例、记录是否缺失、曝光/归因口径是否相符；发现分配异常先查明再下结论（参考 [Microsoft SRM 研究](https://www.microsoft.com/en-us/research/articles/diagnosing-sample-ratio-mismatch-in-a-b-testing/)）。跨作品自然流量不能简单套用户随机实验检验或把统计显著当业务价值。多次同时测试/反复看数会增加误判，预设分析与解释边界；不为显著而频繁改终点。
6. 到达既定窗口后按原始回执回看主指标、护栏、样本、执行完整度及替代解释：证据支持→限场景建议采用；可检测差异小或未见→按能力/精度说明、可暂存；负面→停止或修正并留证；样本/数据/分流不足→证据不足，不能说“没有效果”。有用户批准才将候选投入新的真实操作或修改既定经营计划。

可复用观察→先在当前品牌/条件验证→跨品牌可迁移方法候选→维护技能经评审、测试、版本记录与公开发布。单品牌特例、来源未授权内容和客户数据不进入公开库。实验记录字段见 [记录样例](../assets/record-template.json)。

参考 [Microsoft 实验目录流程](https://github.com/microsoft/experiment-catalog/blob/main/experimentation-process.md) 的基线、实验记录及可重复评估，不复制其系统或声称已部署；[在线实验研究](https://exp-platform.com/Documents/2023-03-11EncyclopeiaMLDSABTestingFinal.pdf) 对多重检验的限制用于评估，不套其固定阈值。
