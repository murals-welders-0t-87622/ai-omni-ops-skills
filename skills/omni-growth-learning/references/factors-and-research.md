# 从实际问题到可检验的因素

先确认品牌、产品/服务、对象、目标客户、业务阶段、目标与约束。指标记录来源、账户/商品/作品、期间和时区、分子分母、自然/付费、采集时间、观察窗口及实际发布/费用，标明缺项和回补。看同平台同对象可比期/基线与分布、样本量及季节和活动，不把品牌目标简化为播放量。

| 层面 | 先看真实信号 | 竞争解释与可能动作（都是候选） |
|---|---|---|
| 品牌与产品 | 客户场景、差异、承诺是否有证据 | 说的卖点是否是目标客户在意的；是否换了不相关人群/不匹配承接 |
| 流量与选题 | 曝光、来源、搜索/受众、同窗口样本 | 账号/渠道状态、选题需求、人群错配、发布时间或预算变化；低播放不等于限流 |
| 内容进入 | 封面标题、首画面及有权限的开头留存 | 封面预期和内容是否一致，第一句是否讲清收益；缺点击曝光/留存不倒算 |
| 观看与互动 | 观察分段留存、完播、评论语义 | 结构/节奏、画面、声音、时长、重复信息、人物角色或故事形式；留存峰值可能是重看或不明白，并非必然喜欢 |
| 转化与承接 | 有效访问、询问/表单、订单、服务 | 产品/价格/页面、承诺、入口、客服响应、库存/交付；互动好不等于成交好 |
| 电商与广告 | 流量、支付转化、每单、广告花费/归因ROI | 词/人群、货品、主图详情、活动/客服、账期；ROI不等净利润、归因不与总GMV重复加总 |
| 私域与销售 | 分层、触达偏好、成交、售后与成熟复购 | 用户需求、权益、服务/使用周期、跟进质量；合规授权与客户感受优先；私域不默认投流 |
| 系统与技能 | 原始任务、请求/结果、用户反馈、错误日志 | 输入/路由/能力不支持、数据滞后、提示词方法、程序缺陷或UI/交接；检查实际 schema 与证据，不把页面卡片当执行 |

研究顺序按问题选择：品牌/中台现有证据→已授权平台采集工具/实际作品及评论→现有技能→WorkBuddy专家与技能原文→官方、原作者/GitHub源码及适用资料。记录搜索词、实际取到的来源/版本/日期/授权范围与未读内容；平台没有该指标就说没有，平台规则和术语需以当前官方及实际接口验证。竞品热度仅为线索，不是因果或本品牌承诺。

同一症状列出至少两种合理解释，用可得到的信息筛选：本品牌的差异表达是否清楚？材料/制作能否支持？竞争解释（平台分发、付费、季节、受众、版本和测量）能否被排除？列出优先假设、为何优先、可推翻条件及下一步。不要把其他平台固定分段或阈值直接套到抖音/小红书。
