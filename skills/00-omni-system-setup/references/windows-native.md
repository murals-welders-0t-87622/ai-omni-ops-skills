# Windows 原生安装与安全更新

## 取得正确版本

从 [官网下载页](https://17ai.site/downloads/) 读取当前 Windows x64 发行版本、渠道及安装说明。以 [官网发布接口](https://17ai.site/api/downloads/v1/releases) 和页面的「校验下载文件」取得大小与 SHA-256。用实际下载的 EXE 核对版本、字节数和 SHA-256。读取文件的 Windows 签名状态并按发行说明和用户确认处理测试版，保留操作系统的安全提示。安装或启动前先处理签名异常、摘要不匹配、目标不明或范围不符。

当前原生安装包无需 Docker。已发布的 1.0.13 是 Windows x64 全新安装测试版，随包带 PostgreSQL，安装及数据路径使用英文字符，适用范围与后续版本以官网说明为准。版本页可查看官网发行与手动下载入口。是否支持原位升级由当前发行说明确认。1.0.13 仍处于独立设备真实激活验收阶段，视频剪辑和渲染暂缓。

## 新装和首次核验

1. 核对 Windows 架构、磁盘、网络及目标目录，检查已有实例和同名数据目录。新装选择用户可写的空目录，已有安装和数据留在原处。
2. 在用户的 Windows 会话运行官网安装程序，使用实际安装位置创建的桌面入口启动。按官网要求在应用窗口内完成首次注册和激活，用户在页面直接输入密码和激活码。校验下载、安装成功、窗口启动、注册、激活和登录分别记录。
3. 按 [现有中台与 AI 客户端接入](deployment-and-agents.md) 装配所需客户端技能和品牌 MCP。读回目标品牌和目标实例，记录实际能力与未验证的功能。

## 更新已有安装

先核实当前版本、安装身份、程序和数据位置、品牌、许可状态及在途任务。查看应用的「个人中心 → 版本与更新」和官网适用说明。新版本通知可以提供官方下载信息。只有发行方明确支持当前版本的原位升级及数据格式、且有验证过的备份和回退办法时，才应用升级。按受支持流程保全数据库、素材和可迁移配置，并处理需要继续的任务。

首装测试包应放在独立空目录供验证。需要迁移旧实例时，先确定是 SQLite、PostgreSQL 或其他受支持来源及适用的官方迁移途径。从隔离副本验证数据、品牌权限、媒体可读和启动结果，需要单独重连的凭据由用户在目标客户端配置。根据结果决定切换，保留旧实例用于复核和回退。
