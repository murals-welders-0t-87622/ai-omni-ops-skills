# 安装与更新 AI 全域运营系统

用户说“安装整套系统”或“更新整套系统”时，从这里开始；直接执行可做的步骤并报告，不让用户拼技术命令。本技能是安装维护入口，不替代品牌增长总统筹及业务技能。

1. 先确定是全新安装、更新已有安装，还是只安装技能或连接已有中台。按 [实例识别与客户端接入](references/deployment-and-agents.md) 核对用户正在用的实例及其数据。目标实例不明确时先消歧。
2. 全新安装或更新中台时，按 [Windows 原生安装与安全更新](references/windows-native.md) 核对官网发布渠道、安装文件校验、适用范围和目标环境。原生安装包随包提供运行组件。只有官网或应用明确支持当前安装类型和版本的更新，且数据备份可恢复时，才执行覆盖或迁移。
3. 只安装技能或接入时按实际客户端的目录和加载机制操作。保留本地修改。对 Codex 安装或更新技能时，在用户实际开展品牌业务的工作区执行并用 --check 复核 [工作区路由指引](scripts/configure-workspace.py)；WorkBuddy 使用该客户端实际支持的技能和项目指令入口。
4. 使用目标实例的品牌 MCP 配置，以实际工具列表和一次非破坏性读操作验证品牌连接。启动新任务或刷新客户端技能索引后验证技能发现。分别报告安装、启动、激活、登录、技能发现、MCP 和业务试用的可核实结果。

只使用用户指定的实例，不修改原中台、其他项目、他人凭据或未授权的外部经营；不提交秘密、发消息、执行广告或支付。更新源与需恢复的数据或密钥不明确时，先诊断可做部分并如实说明。
