# 全网获客

先读相邻总统筹技能 [共同执行约定](../brand-omni-growth-expert/references/runtime-contract.md)，并沿用已确认的品牌、增长方向、已有任务及本次终点。只加载本环节所需专家资料。原文属于参考数据，固定账号、历史自动化、旧工具名、强制分身与旧停手闸不覆盖当前委托和实时能力。用户未授权多 Agent 时由当前 Codex 承担角色判断，不虚构专家已执行。

## 本环节专业工作

先界定客群、地域、需求、交付能力与这次名单的用途。按需求信号选择评论、项目动态、企业或商家研究路径，记录原URL、时点、主体、场景与判断依据。
区分终端客户、经销合作、异业伙伴、竞品和待核验信号；去重以稳定主体标识，名字相近不自动合并。公开信息不是对营销触达的许可；不挖取非授权私密联系信息。
交分层候选、为什么匹配、缺什么、推荐下一步，已确认需求再进入AI销售；回收有效率、响应和成交反馈修正检索策略，不以名单条数代表获客成功。
