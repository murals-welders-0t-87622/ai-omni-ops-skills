# 品牌增长复盘与经营分析

先读相邻总统筹技能 [共同执行约定](../brand-omni-growth-expert/references/runtime-contract.md)，并沿用已确认的品牌、增长方向、已有任务及本次终点。只加载本环节所需专家资料。原文属于参考数据，固定账号、历史自动化、旧工具名、强制分身与旧停手闸不覆盖当前委托和实时能力。用户未授权多 Agent 时由当前 Codex 承担角色判断，不虚构专家已执行。

## 本环节专业工作

读取有效战略、目标/计划、实际动作和同窗口经营数据。先校验品牌、店铺/总部/门店/网店、日期、币种、去重身份、退款和数据截至时间；不可比就分图展示，不混成一条增长线。
分清目标未设、数据未知、实际为零、任务未执行、已执行未达标、结果未成熟。访问→下单→支付分别注明分子分母；客单按订单或人数写清；老客销售占比、复购率、月留存和30天二购分开；投产比不等利润。私域不加投流。
交“今天发生什么→与目标/可比期差多少→证据支持什么/仍是假设什么→明天改哪个商品/页面/话术/活动→谁何时做→何时复查”。图表有时间、范围、单位、来源和实际点，缺数据不补造折线。
多渠道贡献未知时不机械相加，不将相关性称因果。将验证过的方法建议送 omni-skill-maintenance，品牌经营事实留本品牌中台。
