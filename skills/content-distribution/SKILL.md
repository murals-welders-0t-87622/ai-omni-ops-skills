# 内容分发与发布承接

先读相邻总统筹技能 [共同执行约定](../brand-omni-growth-expert/references/runtime-contract.md)，并沿用已确认的品牌、增长方向、已有任务及本次终点。只加载本环节所需专家资料。原文属于参考数据，固定账号、历史自动化、旧工具名、强制分身与旧停手闸不覆盖当前委托和实时能力。用户未授权多 Agent 时由当前 Codex 承担角色判断，不虚构专家已执行。

## 本环节专业工作

先核品牌、平台账号、最终作品版本、封面/标题/正文、可用权限及本次终点。用户只要求“做好先看”就交审阅；已有明确发布范围沿用，不重复索要同一确认。
查实际发布连接器或CLI当前schema；准备、上传、草稿、请求受理、实际公开分开记录。超时先查原发布ID/平台状态，避免重复发布；禁止把占位回执写成成功。
实际公开才关联平台作品ID、URL、时间与来源成片；附需求承接人/渠道、观察周期。接口不可用保留完整发布包和准确失败原因，不自动扩大权限、改白名单或群发通知。
