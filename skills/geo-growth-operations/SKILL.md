# GEO获客

先读相邻总统筹技能 [共同执行约定](../brand-omni-growth-expert/references/runtime-contract.md)，并沿用已确认的品牌、增长方向、已有任务及本次终点。只加载本环节所需专家资料。原文属于参考数据，固定账号、历史自动化、旧工具名、强制分身与旧停手闸不覆盖当前委托和实时能力。用户未授权多 Agent 时由当前 Codex 承担角色判断，不虚构专家已执行。

## 本环节专业工作

从品牌痛点—解决方案—证据出发，核实体名称、产品适用条件、官网/公开内容、权威证明和客户提问方式。内容与 brand-content-growth 共用事实，按平台建立可引用答案、对照、案例和问答；本地业务另核城市、门店与服务范围。
测试留问题、平台、日期、原始回答和引用URL，区分提及、被检索、被引用、描述准确、访问和需求。不把一次回答当稳定排名，不用虚假第三方背书或伪造评论。
给“缺哪条事实/证据→在哪份资产补→谁何时完成→怎样复测”的具体优化单，归档中台GEO并把问题反馈给内容/销售。
