# 程序化与混合视频制作方法

依据用户给的[罗佳Rodya教程](https://mp.weixin.qq.com/s/kaZCk5qg0bWvn31xcAb37Q)及本轮核读的原项目整理。正文15,258字符、五张技术表与代码示意已读；文章给出16种用途和8个项目入口。本文是面向品牌运营的重新组织，不复制原文提示词，也不保证已渲染这些路线。

## 三个选择轴

先明确内容要帮助哪类客户作出什么判断，再分别选 **叙事/视觉语言、绘制技术、时间轴/输出引擎**。水墨是视觉语言，Canvas/笔刷/着色器是绘制技术，Remotion或HTML逐帧是组织与输出。不能把“3D”“Remotion”当成经营目标。

|技术组合|适合本系统的工作|关键条件|先验证什么|
|---|---|---|---|
|HTML/CSS/SVG|产品功能、文字、流程、图标及UI解说|真实界面与示意界面分开；实测布局|字体、遮挡、放大后清晰度、关键状态|
|Canvas 2D|白板、手绘、二维图表、印刷/像素风|每次由时间重画，笔触参数固定|乱序seek、文字清晰度、笔触跨帧稳定|
|p5.js/p5.brush|彩铅、水彩、绘本材料感|先核版本与可控时间/随机种子|离线资产、同帧一致、输出适配；本轮未实装|
|WebGL后期|晕染、光学、颗粒、辉光、CRT等需要逐像素的效果|作为信息服务的一层，不全片堆特效|GPU可用、GPU/软件路径差别、帧耗时、边缘/透明|
|Three.js|产品结构、材质、空间、数据实体化|真实设计/尺寸必须来自资料；示意不能冒充实物|物体/标注同相机、遮挡/穿插、材质、性能|
|Remotion|精确帧控制、系列模板、参数化版本、复杂声画组合|复用dynamic-video-craft工程与本地固定依赖|帧率、Sequence局部帧、资源就绪、音轨和可解码输出|
|HyperFrames|HTML轨道、动效、讲解、品牌短片|按其当前技能/CLI使用时间轴，不替代用户指定引擎|seek、素材/字幕归属、转换与输出|
|Manim|公式、数学/科学推导、精确几何|需要Python与相应公式排版依赖；不用代码美化代替事实|数值先算、推导成立、低规格预演；本轮未实装|
|Motion Canvas/Revideo|已有TypeScript动画项目的续做|先查原工程/官方当前接口，按用户选型|帧接口、媒体兼容、声音与输出；候选路线|
|Blender|真实三维模型、复杂摄影/灯光/模拟|先核模型、软件/插件、CPU/GPU与预算|短段耗时、模型尺度、采样/噪声和合成；不是全部3D默认|
|实拍/截图＋生成媒体＋代码包装|使用演示、真实证据、真人/复杂动作、产品广告|用户素材优先，核SKU/权限/生成入口实际支持|真实与示意区分，人物/产品一致，音画/抠像边缘|

工具层按需要检查Node、Python/uv、FFmpeg、Git及可用浏览器。不要因为文章列了工具就全装；Remotion/其他软件商用条件、字体、音乐、TTS分别核来源，不能笼统承诺免费。

## 一条时间源

现有STORYBOARD、DESIGN和项目配置继续使用。需要代码视频时补技术简报：输出尺寸/fps、镜头起止、音词锚点/拍点、主物体动作、相机、标注、字幕、声音、资产及事实来源、所选工艺、预演/最终输出与验收。这个制作简报不是新增主业务阶段或新的中台schema。

帧号/时间＋不可变输入＋固定种子决定画面。禁止靠实时钟、未固定随机数、前一帧累计状态、无人控制的CSS播放去录制；同一帧单独、顺序或乱序渲染应一致。笔触/纸纹/剪纸边缘在适当坐标固定，不能每帧随机跳。角色可按风格抽帧，相机仍按输出帧平滑运动。

世界物体、效果、标注共用投影与相机；字幕属于屏幕层。用交互图做视频需把悬停/拆解等交互改成确定的时间函数或明确事件回放，网页可交互不等于已得到视频。

## 声音、数据和资产

有完整配音先用真实时长/词锚对齐，不能为凑镜长切尾或补重复开头。对白、环境声、动作音和音乐分别安排；留有意义的静止和安静，不强制每个动作发声或每片固定几次J/L-cut。ASR/响度/波形只能证明测量项目；实际未听审时不能声称音质已验。

事实片保留每个数字、测量与出处；图表实体单位/比例、轴和文字由同一数据驱动。没有CAD/BOM或实际尺寸就做有标识示意，不能凭商品照片捏造内部结构；点云、建筑、档案、卫星影像各自核数据与许可。字体下载本地并检查中文覆盖，不在每帧依赖外网。

## 先证明，再扩展

用代表帧＋包含关键动作/转场的短运动段证明画面、相机、字体、声音与速度，再扩成整片。记录真实耗时、分辨率、引擎版本、硬件/渲染后端与并发；文章个例“7秒/48秒”、星级和30–60分钟不是本机性能承诺。资源紧张先减预演尺寸和并发，不能为出片关浏览器安全、丢掉媒体/音轨或重启Docker/WSL。

整片验收包含解码、入场/落定/转场边界、结尾、文字遮挡/可读性、事实/SKU、音词同步及许可。帧抽检不等完整观影；按实际检查范围报告。素材/工程、预演、可审成片、已接受/已发布分别归档。
