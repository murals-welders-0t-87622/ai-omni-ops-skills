# 按运营用途选择视觉与技术

使用前先确认这条内容的客户场景、认知任务和可信依据。下列是从教程与原项目转成的选型方法，不是风格排行榜；各路线本轮未逐条渲染验收。

|用途|可用表达|实现切入|最重要的证据/检查|
|---|---|---|---|
|知识解疑、选购教育|逐笔构建、条件对照|Canvas/SVG笔画与相机|先后逻辑、字号、笔画和阅读停留|
|资讯与行业变化|地图/影像上的单个发现|真实影像＋标注＋必要后期|来源时间、实际地域、变化口径|
|软件功能与新手引导|实机操作或标明示意的重建UI|HTML/SVG、录屏、Remotion包装|功能真实、按钮/状态/路径准确|
|硬件/详情页视频|产品摄影、结构或适配说明|实物图/实拍，必要时Three.js|同SKU；内部拆解与尺寸须有依据|
|技术机制|可运行的器械隐喻|等轴测SVG，效果层，必要时3D|机制/读数同模型、深度/遮挡正确|
|经营报告、年度数据|可读二维图或计量实物化|先算数据→Canvas/SVG/Three.js|范围/单位/基线/比例与出处|
|工程实证、测绘|剖面、分层揭示|真实点云/测量→计算→3D|不移动测量点以美化结论|
|城市与文旅|地图、建筑、空间故事|有许可地理数据＋3D/实拍|地点、日期、尺度与重建边界|
|品牌历史与档案|档案细节帮助解释变化|真实扫描件＋光学/圈注|来源、年代、馆藏信息，不伪造档案|
|文化节日|水墨、剪纸、皮影等材质叙事|Canvas/p5笔刷＋适量着色|风格服务品牌价值；不照抄角色作品|
|儿童/亲和教育|绘本、手绘角色|笔触层、局部材质、适当抽帧|清楚动作、合适语言和实际可读|
|情感广告/音乐片|主题动作带来视觉变化|真实或生成素材＋代码合成|音乐/人物授权；品牌进入有理由|
|轻松社媒/萌宠|案件、反差、角色行动|图形排版＋角色动画|情景可读、节奏与品牌承接|
|游戏/怀旧|受限调色、系统内叙事|低分辨率Canvas整数缩放|像素/相机步进、资产不侵入别的IP|
|活动片头/品牌视觉|字形、形状与节奏组织|SVG/Canvas、字形轮廓、时间线|本品牌字体/Logo权利、落版可读|
|公式/理科推导|逐步变换、对应量恒色|Manim或精确矢量动画|推导/数值先验证，动作辅助理解|

镜头简报至少写：客户要理解什么、主视觉/风格规则、哪些对象怎样动、用什么绘制/时间轴技术、真实来源、声音/字幕、预算/性能限制及怎样判断成功。不要只写“高级、水墨、电影感”。

已有本品牌成功表达可形成可复用令牌：配色、字体、版式、节奏、相机语法、声音和品牌进入方式，带适用平台与版本。品牌专属令牌回品牌中台；通用技术放本技能。风格增强不能擅自改变产品事实、已确认脚本或业务终点。
