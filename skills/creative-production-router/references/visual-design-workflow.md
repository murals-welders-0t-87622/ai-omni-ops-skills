# 品牌视觉与设计制作

以本品牌受众、使用场景和本次交付为起点。识别已有标志、产品图、品牌名称、色彩、文字、画幅、平台位置和真实素材；用户已明确直接生成时不强制等待方案确认。

## 视觉方案

1. 为海报、品牌视觉、社交封面、商品主图、人物照片或界面分别明确目标和交付形式。用一句话说明受众看见什么、理解什么、下一步做什么；结合现有品牌资产决定视觉方向。
2. 设计可执行的层级：主信息、次信息和行动入口；安排网格、留白、色彩、字重和画面重点。配色、字体、风格和元素数量依据品牌与使用场景，不把一种审美当通用禁令。
3. 社交画面可按人物主角、多个物件拼贴、完整照片叠字选择方法；参考平台实际展示与裁切区域。原始尺寸和可用画幅以当前模型和平台要求为准，输出后重新检查尺寸与文字可读性。
4. 若需品牌视觉系统，按品牌定位、标志、色彩、字体、辅助图形和应用场景整理可复用规范；界面任务再明确交互状态、响应式、对比度和键盘可用性。设计令牌格式与目标工具版本匹配，不能把旧示例称为当前标准。
5. 基于参考图时保留来源、授权及视觉角色，分析构图、材质、色彩和节奏；文化、文字、宗教或未知来源素材要核实语义与使用范围。图像本身非自动获得商用许可。

## 制作与交付

- 按用户指定的图像服务发现品牌、模型、实时参数；见[中台制作能力](../../brand-omni-growth-expert/references/mcp-production-capabilities.md)。用户已授权的范围内执行，不静默换平台或模型。
- 编辑真实照片时按用户要求保留人物身份、事件和必要场景；原创人物按受众和需求选择，避免把原资料中的特定审美或人群默认扩展至所有品牌。
- 对截图、票据、聊天和界面中的个人信息在交付范围内处理；按原图用途检查文字、品牌名称、Logo、商品形态、尺寸及安全区域。生成模型文字不准确时后期校正。
- 输出实际文件、可编辑源或合理的制作记录、使用来源和未核验项；生成成功不等于用户已批准或平台已发布。对已存在版本做增量修订，不覆盖原文件。
