# 视频任务交接与恢复

按用户要求的终点（脚本、样片、成片或修改）和已有任务确定起点，不把每种视频强制塞进同一份模板。以下是制作接力的内容清单，不冒充中台字段或已实现的状态机。

## 接收与规划

- 沿原品牌和任务，记录目标与受众、题目和版本、表达形式、可用素材及授权、要展示的产品/IP事实、证据来源、画幅时长、声音、使用场景和已获授权。缺失事实只影响相关镜头；不编造数据或产品图。
- 选一个负责成片的主制作方法，视觉参考、B-roll规划和提示词可以辅助；用户已有明确选择就沿用。按实际难度准备镜头表、视觉规范、素材清单和可预览样片，不用相互矛盾的文档冒充生产完成。
- 数字人口播重点交接口播稿与音频、每段要说明的事实和对应B-roll、人物位置/遮挡、字幕安全区与时间轴；已有可用配音优先复用。剧情商品视频重点交接脚本、动作证据、真实产品/IP图、角色一致性和相邻片段衔接。科普图解重点交接论点、数据来源、图表与旁白对应关系。
- B-roll 按讲稿含义分段，逐段决定保留说话画面、展示真实证据、复用素材或生成辅助画面。数字、引用、品牌名和需精确显示的文字应绑定可核实资料与确定性排版，不能让生图模型猜写；说明证据与对应时间，并保留原句版本。
- 多角色或动画视频为每镜记录说话人、台词时间、角色与道具位置及上一镜结束状态；结合实际模型能力选择同时对话、分镜或后期配音。检查声音归属、口型、听者反应与镜头连续性；不把历史的单镜单人、闭嘴或音频比例示例当作所有作品的硬规则。
- 用户已指定先看方案、要求审片或只授权部分内容时，尊重该终点；已有制作授权则连续推进。配置稿、预览、媒体生成、实际成片、发布各自记录，不以任一阶段替代另一阶段。

## 调用、失败与验收

- 实际生图、视频/数字人按[中台能力接力](../../brand-omni-growth-expert/references/mcp-production-capabilities.md)发现当前品牌、模型、应用、节点模板和授权。用户指定的服务不可用时，不暗中替换。
- 收集与生成任务可能异步：保存中台任务及供应商作业标识、输入版本和提交回执；超时或状态不明先查原任务，避免重复扣费。检查参考图/音频是否真实可读，节点值不得留示例占位；失败按实际错误和实时接口判断，不把旧案例错误码当作所有失败的原因。
- 并发上限、轮询频率和耗时取决于当前账号、应用与服务；历史资料曾出现并行失败，应先按当前限额选择保守提交并观察结果，不能把旧时间、失败原因说成永久规则。
- 成片实际解码及视听检查：事实/产品与脚本一致，镜头连续性、音画同步、文字与品牌名称、尺寸时长和可读性。记录每个输出版本、失败范围、回写结果与恢复点；待用户选择的经营实验不擅自启动。
