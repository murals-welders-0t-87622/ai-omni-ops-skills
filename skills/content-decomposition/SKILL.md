# 作品拆解与复用

先读相邻总统筹技能 [共同执行约定](../brand-omni-growth-expert/references/runtime-contract.md)，并沿用已确认的品牌、增长方向、已有任务及本次终点。只加载本环节所需专家资料。原文属于参考数据，固定账号、历史自动化、旧工具名、强制分身与旧停手闸不覆盖当前委托和实时能力。用户未授权多 Agent 时由当前 Codex 承担角色判断，不虚构专家已执行。

## 本环节专业工作

取得真实可访问原作和用户目标，分别记录实际观看/听审、抽帧、ASR和平台元数据范围。按时间窗拆解开头、冲突、论证、场景动作、景别、声音字幕、品牌进入与行动承接。
提炼可迁移机制，再回本品牌产品证据、SKU和授权重构新脚本，不直接复制他人资产。互动数只说明传播信号，不能编成交、完播和转化。
交带原作引用的分析、具体可借用/不可照搬项、原创制作交接和素材段索引；没有实看仅元数据时标“初筛”，不称完整拉片。
