# 新机连接与能力检查

装技能让Codex知道怎么组织工作；登录、账户归属和工具定义必须在新机实际取得。不给用户一张字段表让其填完再开工；Codex先发现已有连接，再只报告真正缺少的业务授权。

|业务|事实入口|中台承接|安装后先做的只读检查|
|---|---|---|---|
|全局/品牌增长|当前品牌、产品/IP/知识、有效增长报告|品牌资料与品牌增长报告|品牌身份、当前报告和最小资料是否读到|
|内容|采集工作区、素材库、日历、历史作品|内容战略/策略/日历/脚本/作品/复盘|原片是否可发现、类型/音频、当前任务和文件链接|
|GEO/全网/达人|已授权研究、公开来源及历史候选|各自工作区与线索/合作计划|真实来源、范围和当前schema|
|腾讯广告|本品牌腾讯广告账户|腾讯线索与计划|账户归属、只读数据和销售回传|
|巨量广告|豆包等当前巨量引擎/千川/本地推连接器|巨量报表快照、诊断、优化计划|实际tools/list与查询；不把“已开启”当加载成功|
|淘宝/天猫|千问办公的真实商家端授权|电商快照、策略与执行/复盘|店铺归属、数据期间和实际返回字段|
|有赞|已授权WorkBuddy有赞连接器等实际能力|私域战略/策略、经营分析、客户/会员、计划与结果|总部/门店/网店、窗口、商品/活动/人群实际对象|
|3Chat|实际组织空间、渠道、客户与沟通权限|AI销售共享客户主档、商机、服务与触达回执|当前空间是否属于本品牌，客户稳定ID能否对应|
|图像/语音/视频|中台当前生成服务与自动化应用schema|素材、作业、作品与版本引用|模型/应用、参数、输入映射、作业查询、结果取回能力|

跨客户端不用假定工具同名或配置自动继承。需要从WorkBuddy/豆包/千问取得结果时，使用当前真实且已授权的交接方式，保存原始查询条件与回执；只有聊天里的“我已完成”不足以证明供应商动作。

不存在统一业务权限时准确标缺项。已授权本品牌中台写入不加重复临时租约；对外发送、支出、广告修改、活动上线分别遵守实际用户授权和宿主规则。新机安装不更改正式连接器和既有凭据。
