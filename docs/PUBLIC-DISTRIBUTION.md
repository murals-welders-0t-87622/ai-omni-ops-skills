# 公开范围与原始资料

本仓为AI中台配套的通用运营方法、原创制作工程/检查脚本与来源导航。业务框架和23个入口沿原版保留；公开发行整理了知识材料的分发范围，不改变战略、策略、执行和反馈的业务含义。

上一版完整资料含品牌专用配置、历史经营/运行细节和第三方原包。完整私有历史保留为独立私有档案，原文件没有被公开或丢弃。本公开仓使用新的干净历史，避免在旧提交中暴露不适合公开的资料；公开树也不含这些原文。

|资料|公开仓怎样提供|实际工作怎样取得|
|---|---|---|
|通用技能与本仓原创脚本/工程|完整保留，按方法版本维护|安装后按对应SKILL使用|
|专家与原Skill来源|按来源/领域/适用范围导航；不是原文全文|在授权WorkBuddy、品牌资料或可访问原项目中核读|
|第三方项目方法|可复用机制、引用与读取范围；按许可选择性适配|优先官方/原作者、固定版本或内容hash|
|品牌/客户/项目资料|不进入公开Git|本品牌AI中台MCP和授权工程|
|新增公开教程|本仓消化后的方法、采用/不采用说明与来源|根据任务回读必要正文/图表，未读内容标明|

来源导航不能冒充原全文。没有私有档案访问权限时仍可使用公开通用方法，遇到专有方法/数据缺口则按持续学习流程寻找可用原源并准确说明缺项。
